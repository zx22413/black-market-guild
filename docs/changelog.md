# 黑市商會｜設計沿革

本文件記錄設計演變，不定義現行 gameplay。唯一有效規則請讀 [`game-design.md`](game-design.md)；尚未定案事項請讀 [`open-questions.md`](open-questions.md)。

## V0.1～V0.5｜核心系統逐步建立

現有可取得紀錄沒有保留每一個討論點的精確版次切分；以下依主題重建沿革，不能用來反推未寫入現行規則的數值。

- 建立 4 人為基準、6 回合、每人 1000 G、總財富競爭的對局骨架。
- 確立獨資船的 100 G 成本、300 G 成功收入，以及 1d6 的 1～3 沉沒／4～6 抵達框架。
- 納入護衛、海盜、情報商人、走私商人，以及造船廠、航運保險、打撈公司、貿易交易所四類核心內容。
- 建立合資船、每位玩家每回合一艘船的名額限制，以及公開邀請／回應的媒合流程。
- 釐清秘密角色部署、情報商人重擲必須接受、多海盜同時攻擊與合資船算作一艘資產觸發目標等方向。

## V0.6「市場風向」｜雙事件流程

- 將事件分成「回合開場公開的市場事件」與「角色部署後公開的航海事件」。
- 市場事件用於改變獨資、合資、攻擊、風險與收益的策略誘因；不再預告下一回合市場事件。
- 強化以固定 seed、不同策略 Bot、批量模擬驗證平衡的 MVP 方向，並要求規則引擎與 UI 分離。

### V0.6 補充（2026-09-27）

- 定案合資邀請流程：發起招募（不指定對象）→ 應徵 → 發起人挑選 → 未配對者選擇獨資或不出航。原本討論的「公開貼出、手速最快者成為夥伴」改以「發起人從應徵者中挑選」取代，避免數位版中由速度或網路延遲決定結果；同日較早的「指定邀請＋互邀成立」版本亦被此流程取代。
- 定案合資船經濟：成本 200 G、成功收入 700 G，均分；原列為實驗提案的 700 G 經使用者確認後採用。
- 定案成本支付時點、資金不足限制，以及商船供給不限。
- 定案角色部署框架（每人最多一個、可不部署、可重複選、海盜 100 G／其餘 50 G、鎖定時檢查並於揭露時扣款），以及四個角色的目標、效果與衝突處理；出航船隻於投資階段結束時公開。
- 定案資產取得框架與四項資產的價格、效果（採用使用者記得的原始數值；航運保險採用 V0.6 提出的「護衛 +1」新能力），以及最終財富計入資產購買價的一半。
- 新增資產的合資加成：原始資產表為 V0.1 設計、尚無合資概念；V0.6 起邀請者的造船廠與貿易交易所會為合資船提供額外加成。

## 已否決或延後

以下不屬於 V0.6 MVP，不得混入現行規則：

- 複雜合約與自由議價。
- 下一回合市場事件預告。
- 不同比例合資、玩家間保險與附條件收益分配。
- 秘密交易、護航／襲擊／情報委託等額外交易系統。
- 玩家主動操縱市場條件。
- 以未定案的資產能力、走私數值、保險提案或 2 人中立船細節直接實作的設計。
