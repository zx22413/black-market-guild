# 暗潮商戰｜遊戲擴展方向討論摘要（2026-10-25）

**狀態：** 討論紀錄與方向整理，**不是規則**，也不是已採納的決策。本文件不是 gameplay source of truth，其中的機制、數值與世界觀都不得寫入實作或測試；任何一項要採用，都須先經使用者確認，並依 [`AGENTS.md`](../../AGENTS.md) 的流程先更新 [`game-design.md`](../game-design.md)。
**來源：** session「遊戲擴展方向討論」（2026-10-25）。內容以對話為準，AI 提出的建議不等於使用者的決定；使用者明確表態的部分另外標出。
**後續：** 單機入門路線的具體提案見 [`2026-10-chapter-progression.md`](2026-10-chapter-progression.md)。

## 1. 起點：使用者想問什麼

使用者想知道，如果要把遊戲變成「有深度的單機遊戲或多人連線遊戲」還能怎麼擴展。

使用者自己想到的三個層面：

1. 骰值：多重事件。
2. 營地建造。
3. 角色技能延伸。

另外使用者提到想把整個美術世界觀大改，原因是目前的海盜航海「以桌遊來講是比較好入口的題材，但沒什麼印象點」；例如賽博航海。使用者同時說明：因為還沒跑測試，剛做完一個原型，確實要等回饋比較好，這次只是想聊。

## 2. 現有遊戲最有辨識度的東西

討論中的判斷：遊戲已有的獨特核心是**「大家同時秘密下注同一批不公開的骰子」**（護衛押抵達、海盜押沉沒、莊家押市場漲跌、情報商人偷看並重擲）。擴展應該**放大這個核心**，而不是另外接一套新系統。

判斷擴展是否值得做的標準（對照 V0.7 的三個張力）：

1. 擠貨（大家搶同一種貨，價格崩）。
2. 押同一批不公開的結果。
3. 蓋建築與裝船的材料競爭。

新機制要加劇其中至少一項才值得做；單純增加隨機事件三項都碰不到。另一條底線是 `game-design.md` 第 2 節的「每回合只有 3 個決策點」：新機制應讓既有決策更難，不是多一個決策。

## 3. 使用者三個方向的評估

| 方向 | 討論結論 | 注意事項 |
| --- | --- | --- |
| 骰值多重事件 | 比起「更多隨機」，更好的做法是讓骰子成為**資訊與搶奪的對象**：事件讀全桌骰面組合、半公開的共用海象骰、把骰值存到下一回合 | 不可增加決策點；這些都是構想，沒有驗證 |
| 營地建造 | 局內建築再加會讓領先者滾雪球；真正的潛力在**局外**：單機做成跨局成長的據點 | 多人模式的成長只適合外觀與選項解鎖，不給數值優勢 |
| 角色技能延伸 | 從「升級」轉成**變體**（同角色 2～3 種版本）與**具名人物**（有被動能力的船長或顧問） | 具名人物同時有助於解決「沒印象點」 |

## 4. 骨架缺了哪幾軸

對照 V0.7，遊戲的深度幾乎都集中在**一回合內的同時下注**，下列四軸幾乎是空的：

| 軸 | 現況 | 可能長出什麼 |
| --- | --- | --- |
| 空間 | 每艘船都是「自己的島 → 巴扎港」，沒有地理 | 多個港口、航線、距離、要地封鎖 |
| 時間 | 每回合結算完就清空，很少跨回合承諾 | 期貨合約、借貸、預訂、聲望累積 |
| 關係 | 玩家之間只有互打和夾帶 | 結盟、背叛、委託、合資（**`game-design.md` 第 14 節明定不在 V0.7 範圍**） |
| 不對稱 | 只有八座島的特色 | 陣營、人物、角色變體 |

討論中的看法：最大的深度槓桿可能是**空間與時間**，兩者現在都是零。這個看法**未經模擬或試玩驗證**。若真要做，依專案流程要先寫進 `docs/proposals/`，再用 Bot 模擬比較。

## 5. 世界觀討論

使用者想知道有沒有比海盜更有印象點的世界觀，並明說自己沒有特定想像、只是隨手捏一個看看。

討論中提出的候選：

| 候選 | 概念 | 結果 |
| --- | --- | --- |
| 賽博航海 | 把航行骰換成訊號延遲、海盜換成劫掠程式 | 使用者最初提到的例子，未深入 |
| 禁酒令走私 | 私酒、警察、賄賂 | 穩但辨識度普通，未選 |
| 沒頂之城 | 淹沒的城市樓頂當島 | 未選 |
| 記憶黑市 | 貨物是記憶 | 未選 |
| **鬼市／中元水燈** | 陰陽交界的河上做生意 | **使用者明確表示不喜歡** |
| 假面水都 | 威尼斯式商人共和國，摘面具對應角色揭露 | 未選 |
| 鯨島 | 島是巨獸的背，偏空間軸 | 未選 |
| 沙海商隊 | 海乾了，帆船在沙丘航行 | 未選 |
| 雲港 | 浮空群島與飛艇 | 未選 |

**結論：世界觀沒有定案。** 討論還指出另一個重點：世界觀選擇其實是在選擴展方向（假面水都偏關係與時間、鯨島偏空間、沙海商隊偏空間加時間），所以應該**先決定機制往哪長，再選世界觀**。

使用者的回覆是：「其實就是要想如果要延伸機制應該要怎麼延伸」，也就是主要關心機制而不是題材。

另有一項提醒：世界觀若要大改，最好比繼續打磨美術更早決定，因為目前已有大量低面數島嶼、音效與配樂的投資（見記憶中的功能軟凍結：只做視覺打磨）。建議的順序是先跑完 V0.7 試玩確認核心循環好玩，主題的低成本測試（概念圖、標題畫面）放在後面。

## 6. 單機化的討論

### 6.1 回合制與即時制

使用者問：作為單機遊戲不拘泥於回合制會怎樣，好像卡牌桌遊都是回合制。

- 卡牌桌遊多半是回合制，原因是實體桌面的限制；數位版沒有這個限制。
- 現有遊戲是**同時秘密提交、一起揭露**（接近 Marvel Snap）。
- 往即時制走，心理博弈會從「猜你選了什麼」變成「抓時機」，同時揭露的爽點會消失。
- 參考作品：Offworld Trading Company（RTS 的經濟戰）幾乎是「這個遊戲的即時版」。
- 技術上：引擎是 `applyAction` 一步一步推進的純函式，Bot 模擬、重播、連線都建立在回合制之上；即時制要改成 tick 模擬，等於重寫。
- 討論結論：保持同時回合制；節奏感用縮短回合、加快揭露動畫處理。

### 6.2 回到回合制的單機定位

討論中的定位：**「跟有個性的對手鬥心機的策略賭局 roguelike」**。

- 多人版的內容是對手的腦袋；單機版對手是 AI，要把 AI 對手本身當成內容設計：有習慣、有破綻、有脾氣，且讓玩家讀得出來。
- 參考：殺戮尖塔（敵人意圖）、Card Shark、小丑牌（改規則的小道具）、邪惡冥刻（有個性的對手）、Frozen Synapse（同時回合制）。
- 可能的遊玩形狀：一次遠征連打數場，對手是具名商會，場與場之間挑升級，最後有大魔王。
- 關鍵設計旋鈕：**對手意圖公開多少**。全公開變解謎，全隱藏變純賭博，中間（模糊意圖加上情報商人揭露）是這個遊戲的獨特位置。
- 專案資產：規則引擎、同時回合制、四種 Bot 個性、`onEvents` 公開事件記憶都可沿用；要新做的是意圖提示、遠征結構、升級道具池。

### 6.3 單機類型比較

| 類型 | 評估 |
| --- | --- |
| Roguelike 遠征 | 討論中最推薦：引擎幾乎直接沿用，且三個使用者方向（骰子道具、營地、角色升級）都能放進去 |
| 商業模擬沙盒 | 需要空間軸，很可能要即時可暫停，等於重寫 |
| 劇情戰役 | 敘事好做，重玩性較低 |

### 6.4 放置遊戲（點擊放置）

使用者問整個做成放置遊戲會不會很垃圾。討論結論：

- 核心不適合放置：放置的樂趣是數字成長、決策少、幾乎沒有對手，與這個遊戲相反。
- **放置只適合放在據點層**（離線時島繼續生產與升級），主動的商戰維持原樣。
- 風險：放置層的累積若帶進多人商戰會變成掛越久越強，只適合產出選項與外觀，或只用在單機。

## 7. 使用者尚未決定的事

- 要走單機（遠征）、多人，還是兩者並行。
- 世界觀是否更換、換成什麼。
- 擴展先走空間軸、時間軸，還是使用者原本的三個方向。
- 是否放行打破 V0.7 功能軟凍結的新功能。

## 8. 這份討論之後的發展

2026-10-26～27 的後續談話中，使用者表示：

- 不確定遊戲的長期目標，是「心血來潮做的」，但已投入約一個月。
- 認為遊戲本質是電子桌遊，難推廣，希望更多人看到，但不知道原因。
- 因此傾向做成「比較大型的單機遊戲」。
- 觀察到 V0.6、V0.7 給熟人看時「沒辦法馬上懂」，想到做成**線性關卡、一步一步解鎖**。

據此產生了 [`2026-10-chapter-progression.md`](2026-10-chapter-progression.md)，只涵蓋第一階段：用受限規則的真實對局串成入門章節，並建立量測，不含遠征、世界觀與任何新規則。
