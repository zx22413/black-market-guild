# 暗潮商戰｜世界觀方向與 V0.8 關聯（2026-11-02）

**狀態：** 使用者已確認世界觀主方向為「鯨島、雲港，融合適量賽博元素」。此確認不包含下列具體設定、玩法或美術交付範圍的採用。
**來源：** 本次對話，使用者表示「我感覺可以往這個方向訂」，並要求寫入文件。
**邊界：** 本文件不是 gameplay source of truth。現行玩法仍以 [`../game-design.md`](../game-design.md) 為準；涉及玩法的構想須另行確認，先更新該文件，再更新實作與測試。

## 1. 已確認的主方向

- 世界觀以**鯨島與雲港**為主，融合**適量賽博元素**。
- **主要環境為雲海**（使用者於 2026-11-02 確認）。巨鯨與貨船在雲海中如何移動，仍待確認；不據此推定飛行原理或新增航行規則。
- 後續世界觀發想依此收斂；具體地理、科技、生態與勢力尚未定案。
- 這不是已完成的美術重製規格，也不代表既有名稱、商品、角色與資產立即更換。

## 2. 氣質與畫面候選（AI 建議，待確認）

- 鯨島是玩家珍惜的家園；雲港是貿易、走私、查緝與掠奪的利益交會處。
- 氣質：「家園值得珍惜，生意卻很不乾淨。」兼有壯闊、神祕、生活感與商戰的貪婪。
- 科技帶有修補與改裝痕跡：工坊、管線、舊機械與少量發光設備；賽博元素的強度與形式待定。
- 巨鯨背負聚落、貨船往返雲港，是候選主視覺，尚未確認巨鯨如何移動、聚落如何依附，以及貨船如何航行。
- 遷徙航期、資源壟斷、生物與機械結合等，都是先前舉例，並非已確認設定。

## 3. 與 V0.8 的關聯（建議，範圍待確認）

V0.8 可作為新世界觀的起點，不必同時完成所有美術重製。下表只說明題材如何承接機制討論，不新增規則：

| 討論中的 V0.8 方向 | 世界觀對應候選 |
| --- | --- |
| 島裝備與生產成長 | 鯨背聚落的工坊、倉儲與生產設施 |
| 船裝備與航行收益 | 改裝貨船應對航況，外觀呈現升級 |
| 事件前置、環境壓力遞增 | 航行預兆與逐漸不穩定的空域 |

相關機制狀態見 [`2026-11-building-and-structure-notes.md`](2026-11-building-and-structure-notes.md) 與 [`2026-11-role-function-inventory.md`](2026-11-role-function-inventory.md)。世界觀不得反向推定這些機制已採用。

建議先完成世界基本關係、用語與概念圖，再隨機制定型逐步替換美術；具體交付項目與替換範圍尚未確認。

## 4. 長期擴充的題材空間（構想，未採用）

- 不同海域／空域：生態、氣候與事件組合。
- 不同鯨島：聚落文化、生產背景與裝備風格。
- 港口勢力：交易利益、角色背景與市場衝突。
- 航線與多港口：較大型的玩法擴充，須獨立設計與驗證。

世界設定可以預留這些空間，但 V0.8 不因此承諾移動地圖、巨鯨養成、多港口交易、戰役或額外判定。

## 6. 巨鯨形式與《DECA-DENCE》參考（2026-11-02）

**使用者表態：**

- 比起單純的自然巨鯨，更偏向**半機械改造鯨或鯨形機械**，尚未二選一。
- 提出動畫《DECA-DENCE》（《沒落要塞》）作為世界觀討論參考。
- 對全機械方向有所顧慮：「會不會不夠自然」。這不等於已排除鯨形機械，也不等於已選定活體共生。

**AI 討論與建議（未採用）：**

- 參考重點是巨大移動設施承載聚落，以及維修、工作與生活痕跡；不是採用作品完整設定或後段世界真相。作品背景參考：[作品介紹](https://tv.apple.com/us/show/deca-dence/umc.cmc.6vjghgc4x2bghd83lwr6a10is)。
- 半機械鯨可保留呼吸、遷徙與自然動作，機械作為義體、維生裝置或人類外加設施；改造的動機、來源與倫理關係都未定。
- 鯨形機械可呈現古老主體與世代加蓋的碼頭、工坊、管線，並保留尚未完全理解的航行習慣；不據此定案古文明、AI 或自主操控機制。
- AI 起初偏向鯨形機械以承接裝備成長，聽到自然感的顧慮後改為較偏半機械活體；兩者都是建議，沒有取代使用者未完成的選擇。
- 本作可著重多個移動聚落之間的交易、依賴與剝削，保留商戰核心；勢力、生態與具體互動規則尚未定案。
