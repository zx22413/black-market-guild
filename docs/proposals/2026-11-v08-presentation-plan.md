# 暗潮商戰｜V0.8 原型的呈現規劃（2026-11-16）

**狀態：** 工作規劃，**不是規則**。規則仍是 [`../game-design.md`](../game-design.md)（V0.7.1）；V0.8 原型的內容見 [`2026-11-v08-one-page.md`](2026-11-v08-one-page.md)。這份只規劃「怎麼把原型做進真正的遊戲畫面」，不改任何規則數字，也不動線上對局。

**前提（使用者 2026-11-16）：** 試玩只有使用者自己；不做純文字面板的過渡版，直接在 3D 桌面上做視覺；船的升級一定要讓船本身有明顯變化；需要建模的先做設計稿，確認後才建模；一步一步完成。

## 1. 現況：V0.8 在真正的畫面上是什麼樣子

開發網址 `/v07.html?dev=round3d&v08`（2026-11-16 加的開關）可以用 `RULES_V08_PROTO` 在正式的 3D 桌面開一局，你對三個 Bot。引擎和 Bot 都會動，但畫面還在講 V0.7.1：

| 畫面 | 現在顯示的 | V0.8 應該顯示的 |
| --- | --- | --- |
| 選島卡 | 自由港「孤注號船費 0、可裝貨量 −1」 | 所有船費減半；燈塔島的原始骰 3 以上才 +1 |
| 開局 | 沒有暗潮 | 兩個候選暗潮 |
| 回合數 | 「第 1／6 回合」 | 6～10 回合，結束時點不固定 |
| 船卡 | 最終值對「獲利率 25%～75%」 | 最終值對「掉幾箱」 |
| 投資 | 只有選船、裝貨 | 多 1 個材料動作（開技能、蓋建築） |
| 結算 | 船到港或沉沒，貨照百分比算錢 | 箱子一箱一箱掉進海裡，剩下的賣錢；技能觸發 |
| 船 | 五艘船固定外觀 | 開了技能的船多一個零件 |
| 島 | 沒有 V0.8 的建築 | 修船廠、軍械庫、商行其中一棟 |
| 暗潮 | 只有紀錄抽屜的文字 | 暗潮將至、揭曉、倉庫減半、擋下的那一下、最後的大市集 |

## 2. 從類似遊戲學到、這裡要照做的

來源見 [`2026-11-similar-games-comparison.md`](2026-11-similar-games-comparison.md)。

- **一次升級＝船上多一個獨立的零件**（Scythe、Black Flag、FTL）；只換船身顏色或貼圖會被看成小改動。
- **事先知道的威脅要一直看得到**（Kingsburg、In the Year of the Dragon）：兩個候選暗潮開局後要常駐在畫面上，不能只出現一次。
- **一次只演一件事**（本專案結算拍既有的原則）：掉箱一箱一箱演，不一次扣完。
- **規則由程式執行**：畫面只呈現引擎發出的公開事件，不另外算一套。

## 3. 步驟

每一步做完都能實際玩、實際看。順序照「規則有多確定」排，先做不太會再變的。

| 步驟 | 內容 | 要不要建模 |
| --- | --- | --- |
| 0. 畫面說真話 | 船卡改成掉箱表；回合數不再寫「／6」；選島卡的自由港、燈塔島文字；開局亮出兩個候選暗潮並常駐 | 不用 |
| 1. 出航結算（件數制） | 船上看得到幾箱貨；結果出來後箱子從最貴的開始一箱一箱掉進海裡（水花、音效位置先留）；剩下的箱數賣錢；孤注號與海嘯號的倍率 | 不用（用現有貨箱模型） |
| 2. 材料動作與建築 | 進行中（2026-11-17）：舊的四棟程式碼建築不沿用（使用者：不夠精緻，都是多邊體堆砌而成），三棟都在 Blender 重做：設計稿 [`../art/facilities-concept.png`](../art/facilities-concept.png)，使用者已確認方向、封邊與接合處；模型 `public/models/facilities/*.glb`（`scripts/blender/build-facilities.py`）。已放上島：位置在島後方兩塊舊空地之間（`scene/facilityLot.ts`），大小 1.2 倍，是八座島都不壓到造景的最大值（有測試）；桌面狀態從公開事件記錄誰蓋了哪棟、開了哪些技能，倉庫也扣掉材料與暗潮損失，與引擎一致（有測試）。預覽：`/v07.html?dev=facilities`。修船廠改成冷色滑道、深色船身、翠綠屋頂（原本在香料群島的紅土上撞色）。投資的裝貨步驟左側有「材料動作」面板（`table3d/MaterialPanel.tsx`、`table/investChoice.ts` 的 `materialCards`、`withMaterial`、`protectChoices`）：三棟建築與五個船技能各一張卡（圖、效果、要幾箱材料、不能選的原因），商行的主人在這裡指定保護的貨；選了會從可裝的貨扣掉材料。登場與反應（`table3d/facilityShow.ts`、`scene/Facility.tsx`）：蓋好的那回合，出航時島上跳出「修船廠 落成」（開技能是「好兆頭 開啟」），建築從上方落下、壓扁回彈、揚塵；結算時建築發揮作用（少掉箱、海盜少拿、擋下暗潮等，引擎的 `v08-effect` 事件）會在島上跳出一行說明並彈跳一下，跟船有關的在那艘船的結果出來時、跟市場有關的在市場結算完時。預覽：`/v07.html?dev=facilities&raise` 的「落成」「反應」按鈕。鏡頭（2026-11-18，使用者決定）：蓋建築的決定留在港口的材料動作面板（材料和貨是同一堆，要在同一個畫面比較），按下建築卡時鏡頭自己滑到島後方看建築落下、約 2 秒後自己回到船（`ShipSideCamera` 的 `lot`、`lotShot`），取消時不動；出航時有人蓋建築，鏡頭收到有訊息的那幾座島並多停 1.2 秒（`useIslandMoments` 的 `camera`）。造船廠不做成第四棟建築（人人都有、形狀會撞修船廠），改做碼頭邊的工事（使用者 2026-11-18 決定）：開技能那回合船邊搭起施工架，出航時拆掉。粗模設計稿 [`../art/dockworks-concept.png`](../art/dockworks-concept.png)（`scripts/blender/blockout-dockworks.py`）使用者 2026-11-18 確認方向，細修中：五艘船各套過一次（施工架與工作筏依船寬往外擺，離船身的距離相同）；封邊（踏板的深色擋邊、樁腳的柏油、帆布的橫杆與邊條、木筏的邊框）與接合（橫木綁紮、樁頂銅帽、梯腳擋木）；改前改後對照 [`../art/blockouts/dockworks/refine-before-after.jpg`](../art/blockouts/dockworks/refine-before-after.jpg)。使用者 2026-11-18：施工中帆不用收；蓋的時候要把船遮起來，要有搭鷹架的過程與煙霧。分鏡 [`../art/dockworks-storyboard.png`](../art/dockworks-storyboard.png)（**待使用者確認**）：立樁 → 架板 → 拉布（前方大幕升起遮住船）→ 施工（煙霧，船在裡面換成升級後）→ 揭幕 → 收工；自己選技能時播前五拍，施工架打開留到出航；對手的在出航公開時播遮著、揭幕、收工。**還沒做：** 建模匯出與做進遊戲；整桌鏡頭幾乎俯視，大幕是側面的，從上面遮不住船，只有煙霧那一拍遮得住；海嘯號船尾的槳離施工架最後一根樁很近，沒有近看確認。**還沒做：** 落成與反應沒有音效；出航時只有一座島有訊息的單島特寫沒看過（試玩那局四座島都有訊息，等於整桌）；手機上鏡頭帶去島上時面板會不會擋住建築沒看過；手機版面沒測；整桌視角下自己的名牌可能蓋到島後方的建築；落成訊息與結算時的說明只在預覽頁看過動畫，沒在完整對局裡看過。 |
| 3. 船技能 | 五艘船各一個零件（開了技能才出現）＋觸發演出：好兆頭重擲、加注 ×4、拾荒、自帶掩護、巨浪加骰 | **要**：五個零件，先出設計稿 |
| 4. 暗潮 | 暗潮將至（海變色）、揭曉是哪一種、倉庫減半、建築擋下的那一下、事件卡翻成 Boss 面、最後的大市集 | 可能要（四種暗潮的海面效果多半是程式特效；若要實體道具再出設計稿） |

建築提前到第 2 步（使用者 2026-11-16 同意）：Bot 幾乎都在第 1 回合蓋建築，試玩第 1 回合就會碰到；做完第 2 步就能完整玩暗潮來之前的回合。

第 0、1 步不需要建模，可以直接做；第 2、3 步開始前先交設計稿。

## 4. 第 3 步的零件方向（AI 的提案，還沒確認）

每艘船的技能零件要從遊戲鏡頭（約 54° 俯角、縮到很小）看得出來，而且跟那艘船原本靠來辨識的特徵不衝突（[`../art/ship-silhouettes.md`](../art/ship-silhouettes.md)）。以下只是起點，正式提案會做成 Blender 粗模的設計稿再給使用者選：

| 船 | 技能 | 零件方向 |
| --- | --- | --- |
| 信天翁號 | 好兆頭：要沉時重擲一次 | 待設計稿 |
| 孤注號 | 加注：只有 6 到港，×4 | 待設計稿 |
| 巨鯨號 | 拾荒：撈別人沉船的貨 | 待設計稿 |
| 幽靈號 | 自帶掩護 | 待設計稿 |
| 海嘯號 | 巨浪：骰到 6 再加 1d3 | 待設計稿 |

## 6. 進度

| 步驟 | 狀態 |
| --- | --- |
| 0. 畫面說真話 | 完成（2026-11-16）：船卡是掉箱表（含自己的建築、風暴潮、這回合的修正）；回合數不寫總數，最後一回合會標出；選島卡、島徽章、排行的自由港與燈塔島文字；左上角常駐暗潮晶片（兩個候選 → 揭曉後那一種，滑過看效果與擋得住的）。暗潮晶片的圖示是暫用的，第 4 步再做。 |
| 1. 出航結算（件數制） | 完成（2026-11-17）：結算拍先打開貨艙，掉的箱子一箱一箱被拋出船舷落水（水花、水面圈、落水處跳「−1」與貨的圖示），船旁的標籤把掉的箱子劃掉並寫「掉 N 箱」，掉完船才進港。資料只用引擎的公開事件（`ship-resolved.lost`）；掉的是哪幾箱是準的，演出的先後順序固定照軍火、香料、鐵礦、木材。預覽：`/v07.html?dev=beat3d&v08`。還沒做：掉箱的音效、孤注號與海嘯號倍率的演出、沉船時整船貨的演出沒變。 |
