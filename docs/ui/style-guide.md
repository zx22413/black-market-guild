# UI 風格指南

> 狀態：草案 v0.5（2026-10-01）。排版規則見 [`layout-spec.md`](layout-spec.md)。
> 樣張：開發伺服器的 `/?dev=ui-mock`（`src/ui/dev/uiMock/`），參數 `v=flat|props|mix`、`font=wenkai|iansui|song`、`tone=now|ftk`；截圖在 [`mockups/`](mockups/)（`v2-*.jpg`、`v3-*.jpg`）。第一版靜態樣張 [`mockups/table.html`](mockups/table.html) 保留作對照。

## 已定方向

- **主方向 C：實體桌遊道具**。會被拿起、翻開、蓋章的東西才有外形，例如卡牌、紙條、錢幣、封蠟、木牌。
- **極簡**：HUD 只佔畫面四周，場景中央保持乾淨。常駐資訊只放名稱、數字、圖示，其餘放 tooltip（見排版規格 §3）。
- **海維持現在的青綠色**（`WEATHER.clear.sea`），不改深藍（2026-10-01 使用者決定）。For The King 只參考 UI 的物件感，不參考海色。
- **字體：霞鶩文楷 LXGW WenKai TC**（2026-10-01 使用者決定）。

## v0.1 的教訓：為什麼有「AI 味」

v0.1（`mockups/table.html`）雖然用了盾形、錦旗、金邊，使用者仍覺得「邊框＋死沉沉的底板」。原因有五個：

1. **同一套配方套在所有元件上**：「金邊＋深藍漸層＋造型輪廓」，只是換形狀。
2. **先畫盒子再放字**：資訊都裝在面板裡，面板本身沒有意義。
3. **太完美、太平均**：線條一樣粗、陰影一樣深、全部對稱；紙紋是程式雜訊，不是真的紙。
4. **UI 與場景的光線、色溫脫節**：白天的島配上夜色的面板。
5. **系統字體沒有個性**。

## 規則（v0.2）

- **不畫面板**。文字與數字直接放在場景上，以多層柔和陰影確保可讀（樣張的 `--lift`），不墊底色、不加框。
- **只有實體物件有外形**，而且每種物件只用一種真實材質：
  - 卡牌、紙條、按鈕、tooltip 用羊皮紙。
  - 招牌、回合板用木頭。
  - 錢幣用金屬。
  - 私密資訊用封蠟。
- **材質用真實掃描貼圖**，不用程式雜訊。來源限 CC0（ambientCG、Poly Haven），記錄在 [`mockups/SOURCES.md`](mockups/SOURCES.md)。
- **允許不完美**：紙張撕邊（每個元件隨機但固定的鋸齒輪廓）、卡牌微傾、手繪筆刷底線、印章略歪。
- **標示用印刷與蓋印**，不用 UI 元件：價格是紅色圓形戳記，關鍵字是紅色點線底線，座位色是筆刷底線或菱形色點。

## 對局 HUD（試用中）

- **版面與行為不變**：沿用原本 HUD 的分區與元件（`scene.css`、`table.css`），只替換外觀，外觀集中在 [`src/ui/table/hudSkin.css`](../../src/ui/table/hudSkin.css)。使用者指示：設計邏輯維持原本的，風格換成手繪。
- **輕量版零件**：
  - 要讀的東西用小紙片 `paper-small`：事件公告、名牌、船標、操作列、卡牌、說明。
  - 牌子與按鈕用小木牌 `button-tag`：回合數、黑市港、按鈕。
  - 自己的帳本（左下）是**紙釘在木板上**：三片木板拼成的 `board-wood` 墊底，紙片略歪、上方兩角各一顆紅色圖釘（使用者指定，不用框住）。
  - 較大的面板用細木框 `frame-thin` 包紙：只有你知道、航海日誌、結算。
  - 圖示按鈕用圓木片。
- 對手名牌左端綁一條**座位色的繩子**：微彎、有扭轉斜紋、頂端打結、底端垂下一小段；顏色來自 `--seat`（由 `SceneLabels` 設定），形狀用 `rope-mask-outer`／`rope-mask-inner` 遮罩。不要用筆直的色條（使用者回饋）。事件公告上有一顆釘子。
- **顆粒雜訊（淡）只用在紙上**：SVG 內以 `feTurbulence` 疊上深、淺兩種斑點，只套在紙的填色，輪廓線保持乾淨（套到輪廓會變毛）；**木頭不加雜訊**（使用者指定）。強度調整 `scripts/draw-ui-art.ts` 的 `GRAIN_STRENGTH`（目前 0.6）。
- **木頭上色**：一條由亮到暗的平滑漸層＋筆觸木紋與節疤；不要用「亮、中、暗三條色帶疊起來」的畫法，看起來像一層層疊的，不像木板（使用者回饋）。
- 截圖：`mockups/hud-v4-buy.jpg`、`hud-v4-apply.jpg`、`hud-v4-voyage.jpg`。

## 第四版：手繪卡通木頭（已套用到設定畫面）

使用者提供的參考設計稿（手機遊戲的「連線」畫面）確立了方向：**不是照片、也不是純平塗，而是手繪卡通風**。

- **材質是畫出來的**：粗的深色輪廓線、平滑的明暗漸層、少數筆觸木紋、節疤、釘子、缺角。羊皮紙是米色平塗，邊緣暈暗。
- **裝飾外重內輕**：
  - 最外層最華麗：大木框、繩子、標題木牌。
  - 內頁是安靜的羊皮紙。
  - 內容格是平塗的淡棕色，完全不裝飾。
- **單一色系**：暖棕、赭色，加上少數狀態色（綠色膠囊表示啟用或已連線）。暖色 UI 壓在青綠的海上，形成冷暖互補。
- **造型打破方框**：標題木牌壓在框的邊線上，主要按鈕是箭頭形木板，圓形木片當小按鈕。
- **做法：切圖**。零件是 `public/art/ui/*.svg`，由 `scripts/draw-ui-art.ts` 產生（`npm run art:ui`），畫面用 CSS `border-image` 做九宮格拉伸。將來有美術畫的 PNG 時，直接替換同名檔案即可。
  - 九宮格的邊條會被拉伸，節疤、釘子只能畫在角落。
- **選單背景**：用遊戲 3D 桌面的模糊擷取畫面（`table-backdrop.jpg`），不用古典油畫，避免兩種畫風衝突。
- 全域字體改為霞鶩文楷（目前由 Google Fonts 載入；`TODO` 正式版改為自行託管子集化字體）。

設定畫面：[`src/ui/screens/SetupScreen.tsx`](../../src/ui/screens/SetupScreen.tsx)、[`setup.css`](../../src/ui/screens/setup.css)。截圖在 `mockups/setup-v4.jpg`，零件總覽在 `mockups/ui-art-parts.jpg`。

## 第三版（`v=mix`）：三種材質分工

使用者對 v2 的回饋：兩版各有優缺；羊皮紙排版乾淨但全是羊皮紙太乏味；喜歡木板但深色木頭太重；無底板版左上、左下資訊太密，陰影不得不很重；金幣材質太醜；羊皮紙雜訊太重。第三版的做法：

| 材質 | 負責 | 做法 |
|---|---|---|
| 淺色木頭（`tex/wood-light.jpg`） | 常駐、結構性資訊：對手名牌、回合板、自己的帳本、按鈕、系統鈕、私密資訊圓片 | 大片、柔和的彎曲年輪（不要細密橫紋，會像一層層疊出來）、偏沙色；鋸切的不規則邊、上亮下暗的厚度感 |
| 羊皮紙（`tex/parchment.jpg`，已調淡） | 要閱讀的內容：卡牌、事件公告（圖釘釘住）、決策提示、說明框 | 紋理對比約為 v2 的一半，貼圖尺寸放大 |
| 點綴 | 身分與狀態 | 座位色帆布條綁在木牌左端；紅色印章表示狀態；金幣 |

- 名牌改成畫面上的淺木小牌掛在島上方（不是 3D 招牌），可以顯示約 7～8 字，也不會遮住島。
- 左上只留「回合木牌＋兩張釘住的公告」；左下只留名字與金額，資產估值與黑錢收進旁邊的淺木圓片（滑過顯示）。
- **不要太真實**：場景是平面著色的 low-poly，UI 的物件要跟著風格化。真實金屬反射、紫色封蠟這類寫實或跳色的東西會跟場景不搭（使用者回饋）。
- 3D 金幣：10 邊形、平面著色、用 `SWATCHES.gold`／`roofGold` 的 Kenney 金色，沒有金屬反射；最上面一枚有略小的淺色面板當壓印。每堆最多 5 枚、每 100 G 一枚。（凸邊＋內凹的旋轉體版本被說像金元寶，已棄用。）
- 畫面上的錢幣圖示：同一套 Kenney 金色的雙色平面硬幣（外圈＋內面＋一道高光），不做金屬光澤。

## 研究：low-poly 遊戲的木頭 UI（2026-10-01）

參考了 Kenney UI Pack: Adventure、Len's Island、Kingdoms and Castles、Cozy Grove、Timberborn，以及 itch.io 上的手繪木頭 UI 素材。結論如下：

- 風格化／low-poly 遊戲幾乎不用照片木紋或紙紋。
  - 木頭靠暖棕色加上外形表現（斜切的牌子、平塗的厚邊、鐵角、釘子）。
  - 紙是平塗米色加細框。
- 需要看得出是木頭時，用平塗底色加少數幾筆手繪木紋線與節疤。
- UI 的份量常來自遊戲本身 3D 模型的渲染圖當圖示，例如 Kingdoms and Castles、Len's Island。
- 最接近本專案的是 Kenney UI Pack: Adventure：跟桌面的 Pirate Kit 是同一個作者、同一套平塗畫風，而且是 CC0。

因此第三版用照片掃描貼圖（ambientCG）是錯的方向，跟平面著色的場景是兩種畫風。第四版改為平塗材質。

## v2 的兩個版本（對照用）

| 版本 | 內容 | 優點 | 限制 |
|---|---|---|---|
| **無底板**（`v=flat`） | 名牌、回合、事件、帳本都是場景上的文字；卡牌、按鈕、說明是紙 | 最乾淨、最好讀，改動量小 | 3D 場景本身的份量要夠，不然畫面會空 |
| **3D 道具**（`v=props`） | 各商會資訊畫在島後方的木招牌上，錢是島上的金幣堆，回合是海上的木板 | 最有「桌遊實體感」，資訊跟島連在一起 | 桌面鏡頭下每單位只有約 6.5px，招牌必須做到接近島寬才讀得到字；長名字只顯示約 4 字；會遮住島的後半部 |

兩版可以混用，例如：對手資訊用 3D 招牌，自己的資訊與操作留在 HUD。
