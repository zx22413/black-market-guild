# V0.7 裝貨步驟的版面（2026-10-31）

> 狀態：已實作。程式在 [`src/ui-v07/table3d/useInvestStep.tsx`](../../src/ui-v07/table3d/useInvestStep.tsx)、[`Table3DScreen.tsx`](../../src/ui-v07/table3d/Table3DScreen.tsx)、[`RestockTag.tsx`](../../src/ui-v07/table3d/RestockTag.tsx)，樣式在 `beats/beat.css` 與 `table3d/hudPhone.css`。這份只記「為什麼這樣排」；規則數值以 [`../game-design.md`](../game-design.md) 為準。

## 起因

玩家回饋：看不出貨物什麼時候會補、「囤貨時機不直觀」；手機版裝貨畫面太擠。補貨資訊要加，但這一頁（貨箱、船、建築、對手名牌、提交列）已經滿了，所以做法是**先讓出空間再加**，不是多疊一層。

## 做法

1. **近鏡頭。** 裝貨時鏡頭收緊到自己的島與碼頭，貨箱放大到看得出商品。取景點在 `useInvestStep` 的 `camera`：電腦與手機都只收自己的島、碼頭與自己的名牌，不再把中央巴扎港框進來。手機的島寬度本來就等於螢幕寬度，所以只切掉島的左右兩側。
2. **對手資訊交給別處。** 對手的島在近鏡頭裡看不到，名牌會被推到畫面邊緣疊成一團。電腦版改成自動打開排行（`closeShot`），手機版改成黑市列下方一排小名牌（`rivalRow`）。這一步裡其他玩家原本掛在島旁的名牌與島名牌會隱藏。
3. **補貨時鐘。** 每疊貨箱一個「時鐘＋數字」，數字是還有幾回合這座島會再生產該貨（`restock.ts` 的 `nextProductionRound`，吃各島特色；之後不再生產顯示「–」）。滑過或點一下說明第幾回合。沒有貨的貨箱也顯示。
4. **標籤站在貨箱頂端，不掛在腳下。** 選了建築時，建築預覽會升進貨箱腳下的位置，掛在那裡的數量卡、時鐘、倉庫提示都會蓋住它。所以數量改成單行小卡（商品圖示＋數量），時鐘疊在它上面，倉庫提示移到自己名牌正下方。自己的名牌在近鏡頭裡從島的最前緣移到「＋建築」下方（`OWN_PLATE_REACH`），不然會被提交列蓋住；自己的島名牌往北挪（`OWN_BADGE_LIFT`），讓出頂端的位置。
5. **定位用像素，不用場景距離。** 標籤釘在貨箱的點上，再用固定像素排開。早期用場景單位偏移，鏡頭一拉近間距就跟著放大，標籤卻不變，時鐘離貨箱越來越遠。
6. **手機提交列。** 左右留白縮小讓三個小標籤和封蠟章同一排，ⓘ 放在列內右上角，淺色字。

## 試過、放棄的

- 在倉庫旁放一個漂浮標籤、或併進右上角回合標籤的第二行：島旁已經有最多五六個條件式提示，再加只是更擠。
- 對手名牌排成一排（電腦版）：仍然亂，改用排行。
- 手機不拉近鏡頭：貨箱太小；拉近後才有位置放標籤。
- 數量卡與時鐘整組搬到貨箱上方（大張版）：蓋住貨箱上蓋和島名牌。改成單行小卡才行。
- 選了建築時把時鐘收起來：時鐘應該一直看得到。

## 還沒做或沒驗證

- 其他步驟（部署角色等）的手機版面沒動，仍是名牌貼各自的島。
- 3 箱以上的高貨箱堆頂端的時鐘與島名牌的距離只看過 2 箱高。
- 1920 以上的寬螢幕沒看。
- 手機上補貨提示點開後點別處能不能收起來，只在測試工具裡沒收起來，沒在真機確認。

## 新手教學

「四種貨」那一課新增一句時鐘的說明，並圈出四個時鐘（聚焦目標 `restock`，對應 `data-restock`）。其他課的聚焦目標（`island`、`crate`、`plate`）在新排法下仍對得上：`island` 圈的是船旁提示加倉庫提示，範圍就是整座島。
