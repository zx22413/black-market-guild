# 對局畫面排版規格（Layout Spec）

> 狀態：草案 v0.2（2026-09-30）。本文件只管**排版**：分區、資訊分層、文字預算、字級與斷行。風格（配色、材質、形狀）見 [`style-guide.md`](style-guide.md)，樣張見 [`mockups/table.html`](mockups/table.html)（以 Vite dev server 開啟 `/docs/ui/mockups/table.html`）。
>
> 本文件不涉及任何規則內容；縮短文案時不得改變規則意義，被移出的說明一律移到第二層（tooltip），而不是刪除。

## 1. 支援解析度

| 等級 | 視窗 | 說明 |
|---|---|---|
| 基準 | 1600×900 | 設計稿與截圖以此為準 |
| 最低（桌面） | 1280×720 | 所有元件不得重疊、不得超出畫面 |
| 緊湊 | 1024×768（含開發用 800×600 瀏覽器窗格） | 允許改用「緊湊版面」（見 §2.3），但仍不得超出畫面 |
| 手機直式 | — | `TODO`：Capacitor 打包前另行規劃，本版不處理 |

## 2. 畫面分區

### 2.1 區塊圖（基準解析度）

```
┌──────────────────────────────────────────────────────────────────────┐
│ [A 頂列-左] 回合｜市場事件｜航海事件            [B 頂列-右] 略過 日誌 離開 │  高 ≤ 72
│                                                        ┌───────────┐ │
│                                                        │ C 側欄     │ │
│                     S 場景安全區                        │ 只有你知道 │ │
│              （島、船、名牌、骰子等場景標籤）            │ ／航海日誌 │ │
│                                                        │ 寬 300     │ │
│                                                        └───────────┘ │
│ ┌──────────┐ ┌──────────────────────────────┐ ┌───────────────────┐ │
│ │ D 帳本    │ │ E 決策列（提示＋按鈕）         │ │ F 手牌             │ │  高 ≤ 150
│ │ 寬 ≤ 240  │ │ 彈性寬度，置中                  │ │ 寬 ≤ 320          │ │
│ └──────────┘ └──────────────────────────────┘ └───────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 分區規則

1. **每個 HUD 元素只屬於一個分區**，分區之間不重疊。底部三欄 D／E／F 以同一個 grid（`240px 1fr 320px`）排列，取代目前 `.hud-dock` 的 `left/right: 300px` 與 `.card-hand` 的獨立 `position: fixed`。
2. **F 手牌屬於底部列的一欄**，不可浮在 E 上方或超出視窗下緣。手牌沒有牌時，F 欄保留寬度（避免決策列左右跳動）。
3. **C 側欄一次只顯示一個面板**：「只有你知道」與「航海日誌」共用同一欄（切換或分頁），不再上下疊放。
4. **場景安全區 S 由分區推導**：`TableScene.tsx` 的 `SAFE_AREA` 必須等於 A 的高度、底部列的高度、C 的寬度（C 收起時為 24），不可另寫一組數字。
5. 場景標籤（名牌、船標、骰子）只能出現在 S 內；靠近邊緣時要夾回 S 內，不能被 HUD 蓋住。

### 2.3 緊湊版面（寬 < 1280 或高 < 760）

- 底部列改成兩列：上列 F 手牌置中，下列 D（收合成一行「資金／資產／黑錢」）＋ E。
- A 的事件卡只顯示名稱，效果移到 tooltip。
- C 側欄預設收合，只留按鈕。

## 3. 資訊三層

| 層 | 呈現方式 | 放什麼 |
|---|---|---|
| **L1 掃一眼** | 常駐 | 名稱、數字、圖示、當下狀態 |
| **L2 想知道** | 滑過（桌面）／長按或點 ⓘ（觸控）→ tooltip | 效果說明、計算細節、括號補充、完整名稱 |
| **L3 查閱** | 航海日誌、規則說明 | 過程紀錄、歷史、完整規則 |

判斷原則：

- **括號裡的文字一律是 L2**。例如「（獨資成本 100 G，抵達收入 300 G；造船廠可折抵）」要移到 ⓘ tooltip，不再跟主句擠在同一列。
- **「過去發生了什麼」是 L3**。名牌只顯示「現在」的狀態；「已撤回招募、應徵了誰」這類過程寫進日誌。
- 同一個資訊只能有一個 L1 位置，例如自己的資金只放在帳本 D。

各內容的歸屬：

| 內容 | L1 | L2 | L3 |
|---|---|---|---|
| 市場／航海事件 | 事件名稱＋圖示 | 效果文字 | 日誌 |
| 資產卡、角色卡 | 卡名、圖示、價格 | 效果（`.card-tip`） | — |
| 決策提示 | 一句主句＋按鈕 | 成本、收益、限制條件 | — |
| 玩家名牌 | 名字、資金、資產圖示、**一個**狀態徽章 | 完整名字、資產名稱、狀態說明 | 招募／應徵過程 |
| 船標 | 擁有者色點、角色圖示 | 擁有者全名、角色說明 | 修正明細 |
| 金流飄字 | `+450 G`＋短標籤 | — | 完整原因 |
| 私密資訊 | 每則一句 | 細節 | — |

## 4. 文字預算

「字」指中文字；英數兩個算一字。超過預算時照「溢出處理」欄處理，**不可縮小字級來塞**。

| 位置 | L1 上限 | 行數 | 字級 | 溢出處理 |
|---|---|---|---|---|
| 按鈕（動詞） | 6 字 | 1 | 16px | 改寫文案 |
| 按鈕（含玩家名） | 動詞 2 字＋名字 | 1 | 16px | 名字依 §4.1 截斷；動詞移到提示句 |
| 決策提示主句 | 16 字 | 1 | 16px | 移到 ⓘ（L2） |
| 卡名 | 5 字 | 1 | 14px | 卡片寬度需容得下 5 字（見 §6） |
| 卡片價格 | `400 G` | 1 | 14px 粗體 | — |
| 事件名稱 | 7 字 | 1 | 16px | — |
| 事件效果（L1 顯示時） | 20 字 | 2 | 13px | `line-clamp: 2`＋tooltip |
| 名牌狀態徽章 | 圖示＋4 字 | 1 | 12px | 只顯示優先度最高的一個（§5） |
| 船標 | 色點＋圖示，不放名字 | 1 | — | 名字移到 L2 |
| 金流飄字 | `±N G`＋4 字 | 1 | 15px | 標籤改短版，完整原因寫進日誌 |
| 私密資訊每則 | 30 字 | 2 | 14px | 用色點代替船主名字串 |
| 日誌每行 | 不限 | 自動換行 | 13px | 捲動 |

### 4.1 玩家名字

- 輸入上限維持 12 字（`SetupScreen.tsx` 的 `maxLength=12`）。
- 在名牌、按鈕、船標等 L1 位置最多顯示約 8 字，超過以「…」截斷（`text-overflow: ellipsis`）；完整名字放 L2（tooltip）與帳本、結算表等寬度足夠的地方。
- 名字一律搭配座位色點，讓玩家靠顏色辨認，而不是只靠文字。

## 5. 名牌狀態徽章

名牌同時間只顯示**一個**狀態徽章，依下列優先度取最高的一個：

1. 留港
2. 應徵中（對象用色點表示，名字放 L2）
3. 招募合資中
4. 已撤回招募 → 不顯示，只寫入日誌

名牌高度因此固定為：名字列＋資金列＋資產圖示列＋徽章列，最多 4 列。

## 6. 字級與元件尺寸

| Token | 大小 | 用途 |
|---|---|---|
| `--fs-caption` | 12px | **最小字級**；只用於標籤、徽章 |
| `--fs-small` | 13px | 事件效果、日誌 |
| `--fs-body` | 14px | 卡名、私密資訊、帳本列 |
| `--fs-ui` | 16px | 按鈕、提示句、名字 |
| `--fs-title` | 20px | 回合數、事件名稱 |
| `--fs-display` | 28px 以上 | 骰值、結算標題 |

- 目前小於 12px 的 `0.68rem`、`0.7rem` 都要改成 `--fs-caption`。
- 卡片最小寬度 = 5 字 × 14px ＋ 左右內距 16px ≈ **96px**（目前是 84px）。
- 觸控目標最小 44×44px。

## 7. 斷行與溢出（CSS 慣例）

| 情境 | 做法 |
|---|---|
| 標題、提示句、按鈕 | `text-wrap: balance`（避免最後一行只剩一兩個字） |
| 段落（tooltip、日誌） | `text-wrap: pretty` |
| 限制行數 | `display: -webkit-box; -webkit-line-clamp: N; overflow: hidden;`，並提供 L2 |
| flex 子元素裡的文字 | 子元素加 `min-width: 0`，文字才會換行而不是撐大容器 |
| 名字截斷 | `max-width` 加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap` |
| 數字 | `font-variant-numeric: tabular-nums`，數字變動時寬度不跳 |
| 中文不斷在字中間 | 不用 `word-break: keep-all`（對中文段落會整句不換行）；需要不可斷的詞組時用 `white-space: nowrap` 包成 span |

## 8. Tooltip 規格（L2）

- **觸發方式**：桌面滑過 300ms 後出現；觸控長按，或點 ⓘ 圖示。
- **尺寸與排版**：寬 240～280px，`--fs-body`，`text-wrap: pretty`。
- **位置**：預設在目標上方，碰到畫面邊緣時自動翻到另一側，不可超出視窗。
- **巢狀**：可以有下一層，最多 2 層。有下一層的關鍵字用固定樣式標示（例如底線加特定色）。
- **可達性**：場景標籤層目前是 `.scene-labels { pointer-events: none }`，名牌與船標上的 `title` 因此實際上看不到。要做 L2 的元素必須單獨開啟 `pointer-events: auto`。
- 不使用原生 `title` 當正式 tooltip（延遲長、無法設定樣式、觸控裝置不支援）。

## 9. 驗證方式

1. **壓力模式**（dev 開關）：
   - 所有玩家名稱使用上限長度。
   - 文案加長 30%。
   - 4 人局、玩家持有全部 4 張資產。
   - 用最長的提示句（例如走私商人選目標）。
2. **三種解析度截圖**：1600×900、1280×720、1024×768。每個決策階段各截一張。
3. **自動檢查**：以腳本檢查三件事，結果不為空就算違規：
   - `scrollWidth > clientWidth` 的元素（文字被截）
   - 超出視窗的元素
   - HUD 分區之間互相重疊的矩形
