## 0. 共同原則

1. **一次一個焦點，演出在哪裡、文字就在哪裡。** 說明集中在焦點旁的一張小卡；不另開側欄。
2. **每一筆變化都是「從哪裡到哪裡」。** 錢、貨、角色都用飛行的物件表示，起點和終點都是桌上看得到的東西：島、船、黑市港、看板、建築。眼睛跟著物件走。
3. **出手的人用玩家色標示**：箭頭、角色船的旗、飛行物件的光暈都用出手者的玩家色。
4. **建築做事時會發亮**：保險、打撈公司、交易所生效時，那棟建築閃一下，物件從它飛出或飛進它。
5. **跟我有關的放大，其他的壓縮**（壓縮方式見第 4 節待確認 1）。
6. **節奏：** 每一段自動前進，點一下快轉到下一段；隨時可以「跳到帳單」。
7. **隱私：**
   - 私有事件只在該座位的畫面出現。
   - 同機輪流時，私有事件要在換人遮蔽之後才出現。
   - 公開事件不用遮蔽。

**鏡頭三種距離：**

- **全景**：四島加黑市港。
- **中景**：一艘船加上和它有關的島。
- **特寫**：一艘船。
