# V0.7 介面風格：卡牌桌遊（試用中）

> 狀態：試用（2026-10-19；2026-10-24 加入質感層）。實作在 [`src/ui-v07/skin/layers.css`](../../src/ui-v07/skin/layers.css)、[`skin/ornaments.tsx`](../../src/ui-v07/skin/ornaments.tsx)、[`table3d/islandCard.css`](../../src/ui-v07/table3d/islandCard.css)、[`table3d/rulesBook.css`](../../src/ui-v07/table3d/rulesBook.css)、[`table3d/sealSubmit.css`](../../src/ui-v07/table3d/sealSubmit.css)。網址加 `?skin=classic` 可切回舊外觀比較，島嶼卡、規則手冊、封蠟章除外（它們改的是元件結構，不只是外觀）。各元件新舊對照在 `/v07.html?dev=skin-lab`。V0.6 的手繪木頭風格見 [`style-guide.md`](style-guide.md)。

## 方向

像實體桌遊：**3D 桌面是版圖，拿在手上、做決定的東西是卡牌**。版圖維持原本的 low-poly 白天場景；介面全部是同一個家族——「深色木框裝羊皮紙、金色細線」，和 RPG 卡牌同一套語言。

試過的路與放棄的原因：
- V0.6 每個元件都上木板、羊皮紙、圖釘、繩子，四周太吵。
- 第一版分層（米白代幣＋米紙墨線＋深漆秘密卡）和 RPG 島嶼卡並排時像兩款遊戲，使用者決定全部統一成卡牌風。
- 截 3D 桌面的島當卡面插圖：每座島都是同樣的圓形底座，看不出特色。
- 2026-10-23：材質都有了（木紋、紙紋、金線），介面卻仍顯得扁平。對照 [Game UI Database](https://www.gameuidatabase.com/) 上的 Hearthstone、Hades、Anno 1800、Monkey Island 2 SE、Civilization VI、Wildfrost、Armello、Sea of Thieves、Balatro 後，結論是扁平來自**形狀與光影**，不是材質：元件全是膠囊或圓角矩形、外框只有一條細線、按鈕是單一平色、說明文字下沒有底。改法見下方〈質感：形狀與光影〉。

## 三層

裝飾仍依層級遞增，但材質是同一套：

| 層 | 用在哪 | 外觀 |
| --- | --- | --- |
| 1 常駐 | 黑市列、排行、底欄、島名牌、回合牌 | 斜面木條（頂部亮邊、底部暗邊、淡金細線、底下的厚度）；黑市列與底欄多一道凹槽；**只有底欄**兩端有黃銅端蓋；兩條長木條上的晶片是紙吊牌；島名牌是小木招牌；商會名牌、排行列是**名牌**（見下方）；其他小晶片是羊皮紙代幣 |
| 2 卡牌與面板 | 手牌：建築卡、角色手牌、島嶼卡；面板：帳單、結果、提醒、市場卡、換人、主選單各頁、教學提示卡 | 手牌是卡框（木邊、羊皮紙內面、金色內線、金邊插圖窗）；面板是整張 9-slice 外框（斜面木框、凹槽、紙面下沉的邊、四角黃銅護角），標題掛在上框下的標題牌，帳單、結果、市場卡的紙上印淡淡的羅盤 |
| 3 秘密時刻 | 情報重擲卡、通緝公告 | 深漆底、黃銅細線、燈籠光暈、紅色封蠟章「密」；按鍵是深漆面黃銅邊 |

- 會觸發動作的按鈕（底欄、面板底部、教學提示卡、換人）都是**切角按鍵**：次要是壓印羊皮紙、主要是黃銅，按下時鍵面落到底邊上。回合選單的圓鈕與島上的「＋建築」是桌上的標記，維持羊皮紙代幣。
- 投資與部署的**提交是紅色封蠟章**（見〈插畫要有功能〉）。
- **一層只加一個招牌裝飾**：第 1 層是底欄的黃銅端蓋、第 2 層是標題牌與護角、第 3 層是封蠟與燈籠光。不在每個元件上都加，避免回到 V0.6 的吵。

- 選中的卡：金色內線加粗、外圈金色光暈、卡片抬起。
- 插圖一律白天、海用桌面的青綠色，和 3D 場景接上；夜晚只留給有意義的地方（例如月黑風高事件）。

## 質感：形狀與光影

材質固定只用**木、羊皮紙、黃銅**三種，加一個點綴色**封蠟紅**。質感靠下面這幾種做法，全部是 CSS 與自繪 SVG，沒有點陣圖：

- **斜面**：頂部 1px 亮邊（`inset 0 1px 0`）、底部 2px 暗邊、外圈一條深色邊線、底下一條代表厚度的深色實影，再加落在海上的柔影。
- **凹槽**：離邊緣約 4px 的一圈暗線，下方帶一條淡亮的唇邊，像刻進木頭。
- **切角按鍵**：按鈕本身不畫東西，`::before` 是按鍵的邊框與較厚的底邊，`::after` 是嵌在裡面的鍵面（上半有柔和反光）；按下時鍵面往下移到底邊上。
- **紙吊牌**：尖角一端加一個打孔；吊牌由 `::before` 畫，晶片本身不裁切，陰影和價格變動時的閃光才能跟著吊牌形狀。黑市列吊牌的孔圈是貨品色。
- **面板外框**：一張 9-slice `border-image`（木框、凹槽、紙面下沉的邊、四角黃銅護角）。
- **標題牌**：深木底、黃銅邊、兩端尖角，掛在面板上框下方。
- **名牌**：商會名牌、排行列、島嶼卡上的擁有者、結果畫面的每一列、線上大廳的座位、單機「調整座位」的每一列、教學課程、單機對局的預設方案都是同一種羊皮紙小卡（3px 圓角、頂部亮邊、淡墨內框、底下的厚度），**不做成膠囊**；屬於某個商會的，左側掛一條該商會顏色的書籤緞帶，從上緣翻過來、下端剪成燕尾。大廳與調整座位的緞帶是該座位到了桌上會拿到的顏色（`PLAYER_COLORS` 依座位順序）；大廳的空位沒有緞帶，維持虛線框。輸入框是壓進紙裡的凹框，二選一的切換（真人／電腦、座位數）是紙上的凹槽、選中的是黃銅鍵。手機上電腦座位的名稱欄換到第二行。結果畫面的名次是錢幣（第一名黃銅），「勝利」是鉚在角上的黃銅牌。
- **主選單封面**：遊戲名「暗潮商戰／CONTRABAY」用型板字噴漆直接噴在紙上（深木色、噴漆斑駁加淡淡的噴霧暈邊，中文每字橫切一道型板連接處），旁邊斜蓋一個朱印；是 SVG（`src/ui-v07/skin/titleMark.tsx`），因為噴漆是 SVG filter，而 Safari 對 HTML 文字套 SVG filter 不穩定。字樣來源見 [`docs/title-wordmark.html`](../title-wordmark.html)（H3-A）。其他頁的標題掛在標題牌上。
- **美術層（底圖）**：大面板的紙上印 9% 墨色的羅盤玫瑰與航線，捲動時不動。

實作時踩過的坑：
- `:is()` 的權重取清單裡最高的那一個：把 `.rank-rail li` 和 `.beat3d-pin button.dep-bet` 放在同一個 `:is()` 裡，整條規則就變成後者的權重，後面想覆寫的規則會輸。名牌曾因此一直是 999px 膠囊、玩家色也被 `border: 0` 吃掉。不同家族的元件不要塞進同一個 `:is()`。
- `clip-path` 會連元素自己的陰影、光暈一起裁掉。要跟著形狀的陰影，就把形狀畫在偽元素上（元素本身不裁切），或把 `filter: drop-shadow` 放在外層；`box-shadow` 一律只會畫成長方形。
- 面板內容過長時會在裡面捲動，捲動的容器會裁掉超出邊緣的東西，絕對定位的子元素也會跟著內容捲走。所以面板的護角做成 `border-image`（畫在捲動區外），標題牌改成掛在上框下方，而不是跨出上緣。
- 給 `border-image` 用的 SVG 一定要寫 `width`、`height`，否則瀏覽器會先把圖拉成面板大小再切，護角會變成長條。
- 主選單的 `.menu-panel button` 會蓋過面板裡按鈕的字色；放進主選單的元件，按鈕樣式要限定在元件範圍內（例如 `.rules-book .rules-tab`）。
- 端蓋、吊牌讓元件變寬；手機寬度要另外縮小留白，確認底欄不會多換一行（投資底欄維持兩行 94px）。鏡頭安全區（`useHudSafe`）量的是元件本身，端蓋只超出 4px，在 12px 間距內。

## 插畫要有功能

插畫和道具可以用，但每一個都要先回答：**有了它，玩家能更快知道什麼、或更容易做什麼？** 拿掉它什麼都沒少的，就只是裝飾，不放，或退成低對比的底圖。插畫在介面上能做的事：辨識（不讀字就知道是誰的時刻）、顯示狀態（跟著狀態變）、本身就是操作（插畫就是按鈕）、分類場合（一看就知道是查資料、做決定還是公開資訊）、氣氛（只留給少數關鍵時刻）。

**一個物件只代表一件事**，全遊戲一致，玩家學一次就記得：

| 物件 | 代表 | 用在 |
| --- | --- | --- |
| 書 | 規則與查詢 | 規則面板是航海手冊：書籤就是章節頁籤，翻到的那章書籤最突出、和書頁同色；手機單頁、書籤移到上緣 |
| 封蠟 | 封存、只有你知道 | 提交的封蠟章：按下就是提交，封上後留在底欄寫「已封」、被封住的選擇變淡，直到下一個決定或結算；情報重擲卡的「密」 |
| 朱印 | 遊戲（商號）本身 | 方形、紅底挖出「暗潮商戰」四字（`CinnabarChop`）：主選單標題旁、島嶼卡背、網頁圖示。和圓形的封蠟分開，不拿來表示提交或秘密 |
| 吊牌 | 價格與標價 | 黑市列的價格、底欄的選擇 |
| 告示 | 所有人都看得到 | 通緝公告（提案：做成釘在木板上的告示，不加沒有功能的短刀） |
| 帳本 | 錢的進出 | 提案：帳單做成帳頁，每筆一行、黑字收入紅字支出 |
| 望遠鏡 | 偷看、情報 | 提案：情報重擲卡旁的黃銅望遠鏡，最好就是重擲的操作或在鏡片裡顯示結果 |

不做的：市場卡旁的天秤（刻度與指標已經在表示漲跌）、走私的燈籠（「只有你看得到」已經由封蠟表示）。

**大面積插畫**：遊戲大部分時間 3D 桌面就是背景，大圖只放在桌面退到後面的時刻（結果畫面、航海事件揭曉、載入畫面），做決定的畫面與常駐 HUD 不放。要生成點陣圖時用 `codex`，依本文件的畫風規則下指示並附現有插圖當參考；圖裡不放文字（標題與數字一律用 HTML 疊上）；存成 WebP，全螢幕 2560×1440、手機另裁直式；來源與生成方式記到 `public/art/SOURCES.md`。

## 島嶼卡（試做）

選島與島嶼公開改用 RPG 風格的卡牌（`src/ui-v07/table3d/IslandCard.tsx`、`islandCard.css`），單獨檢視在 `/v07.html?dev=island-cards`（加 `&island=lighthouse` 只看一座）。

- **卡框**：深色木框、金色內框線與四角鉚釘；插圖窗有金邊；島名用燙金字放在紅色緞帶上，壓在插圖下緣；效果列放在羊皮紙面板上。
- **插圖**：向量插畫（`public/art/islands/*.svg`，AI 生成的佔位插圖，來源與限制見 `public/art/SOURCES.md`），平塗、**沒有描邊**（形狀靠亮面、中間調、陰影三種塊面分開；旗竿、桅杆這類結構線保留成深色實線），地標放大當主角，白天配色；八座島都已完成，崖壁與地面用各島在桌面上的顏色，地標畫的是桌面上的大標的物。
- **手作感**：紙紋（SVG `feTurbulence`）、撕邊（`cardCraft.roughEdge`，依島固定）、每張固定的微傾（`cardLean`）、盲壓的羅盤（CSS 陰影做出凹凸）、背面壓進木頭的「黑市商會」。
- **互動**：發牌時背面朝上再翻開；滑鼠在卡上時卡片跟著傾斜，插圖上有一道反光（`pointerTilt`）；減少動態效果的設定下不傾斜、不翻轉。
- 完整規則句放在卡片下方的紙條，卡片本身維持固定大小。

## 插畫與圖示：同一個物件畫兩種尺寸

所有插圖與圖示都不畫描邊（2026-10-19 統一）：形狀要靠剪影與明暗塊面讀得出來，角色卡則是逆光剪影。小道具圖示（金幣、骰子、船、商品）也一樣，淺色的東西（骰子、船帆）靠加深的暗面和羊皮紙底分開。

卡面用插畫，桌上與介面用從插畫抽出來的圖示，造型、描邊、主色都一樣，玩家看過卡就認得桌上的島。依顯示大小選用：

| 顯示大小 | 用什麼 | 例子 |
| --- | --- | --- |
| 約 120px 以上 | 插畫（天空、海、場景） | 島嶼卡、航海事件卡；建築卡與角色手牌的插圖窗（較小，但仍用插畫） |
| 18～64px | 小徽章：主角物件放在天空與海的小圓盤裡，金邊（`IslandIcon`、`IconDisc badge`） | 島名牌、排行、角色章、部署晶片、事件晶片、排行裡的建築 |
| 24px 以下的文字列 | 單色剪影（還沒有用到；圖示檔沒有背景，可用 CSS mask 做） | 晶片、加減列 |

島嶼在 `public/art/islands/`，建築、角色、航海事件在 `public/art/cards/`（網址集中在 `table3d/cardArt.ts`），各自的 `icons/` 是抽出的圖示。金幣、骰子、重擲、船與商品等小圖示在 `public/art/tokens/`（`icons.tsx` 的 `tokenIconUrl`），同樣是彩色、無描邊、無背景，直接放在羊皮紙上（商品放在淺色圓盤裡、外圈是商品色）。V0.7 介面已不再使用 game-icons.net 的圖示與深色圓盤。

角色卡是**逆光剪影**：人物站在一個大亮圓（太陽或月亮）前，身體是一整塊暗色、不畫描邊也不畫五官，邊緣一圈亮光（把同一個剪影換成亮色、錯開幾像素墊在下面）；顏色只留少數點綴：海盜的紅腰帶與刀鋒、護衛的紅羽與白肩帶、情報商人的黃銅望遠鏡與綠圍巾、走私商人的燈籠與發光的眼睛、莊家的紫背心與金幣。剪影要一眼看得出動作：手肘和身體之間留出空隙，每個角色的帽子都不一樣（三角帽、高筒軍帽、寬簷帽、兜帽、高帽）。圖示是同一個剪影的頭像。手牌的插圖窗較小，畫面放大到頭與肩膀。

試過但放棄的：正面的寫實半身像（五個人用同一個臉的模板、手是浮著的圓球）、3/4 側臉的寫實畫法、米寶小人、Q 版大頭。
