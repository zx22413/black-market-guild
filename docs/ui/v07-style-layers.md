# V0.7 介面風格：卡牌桌遊（試用中）

> 狀態：試用（2026-10-19）。實作在 [`src/ui-v07/skin/layers.css`](../../src/ui-v07/skin/layers.css) 與 [`src/ui-v07/table3d/islandCard.css`](../../src/ui-v07/table3d/islandCard.css)，網址加 `?skin=classic` 可切回舊外觀比較（島嶼卡除外）。V0.6 的手繪木頭風格見 [`style-guide.md`](style-guide.md)。

## 方向

像實體桌遊：**3D 桌面是版圖，拿在手上、做決定的東西是卡牌**。版圖維持原本的 low-poly 白天場景；介面全部是同一個家族——「深色木框裝羊皮紙、金色細線」，和 RPG 卡牌同一套語言。

試過的路與放棄的原因：
- V0.6 每個元件都上木板、羊皮紙、圖釘、繩子，四周太吵。
- 第一版分層（米白代幣＋米紙墨線＋深漆秘密卡）和 RPG 島嶼卡並排時像兩款遊戲，使用者決定全部統一成卡牌風。
- 截 3D 桌面的島當卡面插圖：每座島都是同樣的圓形底座，看不出特色。

## 三層

裝飾仍依層級遞增，但材質是同一套：

| 層 | 用在哪 | 外觀 |
| --- | --- | --- |
| 1 常駐 | 黑市列、排行、底欄、島名牌、回合牌 | 素的深木條＋一圈金色細線；上面的晶片、名牌、按鈕是羊皮紙代幣（底下一條深木色厚邊），主要按鈕是金色 |
| 2 卡牌 | 島嶼卡、建築卡、角色手牌、結算卡、市場卡、提醒 | 卡框：木邊、羊皮紙內面、金色內線；圖示放在金邊的插圖窗（天空到海的漸層）裡，之後換成插圖 |
| 3 秘密時刻 | 情報重擲卡、通緝公告 | 深漆底、黃銅細線、燈籠光暈、紅色封蠟章 |

- 選中的卡：金色內線加粗、外圈金色光暈、卡片抬起。
- 插圖一律白天、海用桌面的青綠色，和 3D 場景接上；夜晚只留給有意義的地方（例如月黑風高事件）。

## 島嶼卡（試做）

選島與島嶼公開改用 RPG 風格的卡牌（`src/ui-v07/table3d/IslandCard.tsx`、`islandCard.css`），單獨檢視在 `/v07.html?dev=island-cards`（加 `&island=lighthouse` 只看一座）。

- **卡框**：深色木框、金色內框線與四角鉚釘；插圖窗有金邊；島名用燙金字放在紅色緞帶上，壓在插圖下緣；效果列放在羊皮紙面板上。
- **插圖**：向量插畫（`public/art/islands/*.svg`，AI 生成的佔位插圖，來源與限制見 `public/art/SOURCES.md`），平塗、深色描邊、硬邊陰影，地標放大當主角，白天配色；八座島都已完成，崖壁與地面用各島在桌面上的顏色，地標畫的是桌面上的大標的物。
- **手作感**：紙紋（SVG `feTurbulence`）、撕邊（`cardCraft.roughEdge`，依島固定）、每張固定的微傾（`cardLean`）、盲壓的羅盤（CSS 陰影做出凹凸）、背面壓進木頭的「黑市商會」。
- **互動**：發牌時背面朝上再翻開；滑鼠在卡上時卡片跟著傾斜，插圖上有一道反光（`pointerTilt`）；減少動態效果的設定下不傾斜、不翻轉。
- 完整規則句放在卡片下方的紙條，卡片本身維持固定大小。

## 插畫與圖示：同一個物件畫兩種尺寸

卡面用插畫，桌上與介面用從插畫抽出來的圖示，造型、描邊、主色都一樣，玩家看過卡就認得桌上的島。依顯示大小選用：

| 顯示大小 | 用什麼 | 例子 |
| --- | --- | --- |
| 約 120px 以上 | 插畫（天空、海、場景） | 島嶼卡、航海事件卡；建築卡與角色手牌的插圖窗（較小，但仍用插畫） |
| 18～64px | 小徽章：主角物件放在天空與海的小圓盤裡，金邊（`IslandIcon`、`IconDisc badge`） | 島名牌、排行、角色章、部署晶片、事件晶片、排行裡的建築 |
| 24px 以下的文字列 | 單色剪影（還沒有用到；圖示檔沒有背景，可用 CSS mask 做） | 晶片、加減列 |

島嶼在 `public/art/islands/`，建築、角色、航海事件在 `public/art/cards/`（網址集中在 `table3d/cardArt.ts`），各自的 `icons/` 是抽出的圖示。V0.7 介面已不用 game-icons.net 的角色、建築、航海事件圖示；金幣、骰子、船等小圖示仍是 game-icons.net（深色圓盤），之後可比照處理。
