# 黑市商會｜V0.6 當前規則快照

**狀態：** gameplay 唯一有效規則來源（Current Rules Snapshot）
**適用範圍：** V0.1～V0.6 之中仍有效、且已有明確紀錄的規則。
**不屬於本文件的內容：** 標示為「**待驗證／暫定**」的項目，包含尚未拍板、數值待平衡或原始細節未保存的提案，統一列於 [open-questions.md](open-questions.md)。該文件不是規則來源，不能據此實作或推定規則。

本文件刻意不把「曾討論過」等同於「已定案」。若本文件沒有明定數值、目標或結算結果，該項目就是未定案；不得以設計意圖、舊摘要或 `open-questions.md` 補完。

## 1. 遊戲概念

《黑市商會》是 2–4 人商業、航運與心理博弈策略遊戲。玩家經營商會資產、投資商船，並在每回合的市場條件下選擇獨資或與其他玩家合資。所有人再秘密部署角色，以護衛、情報、走私或海盜行動影響航運結果與收益分配。

遊戲的核心不是單純最大化航運收入，而是在公開市場資訊與有限的對手資訊下，判斷誰值得合作、誰可能背叛，以及是否應為高收益承擔風險。

## 2. 核心設計目標

- 讓市場事件改變玩家當回合的投資、合作與攻擊意圖。
- 讓獨資與合資各自具有合理的風險／報酬定位。
- 讓秘密角色部署形成可推測、但無法完全掌握的心理博弈。
- 讓資產改變合作對象與角色選擇的價值，而非只是被動加分。
- 保持規則可供 Bot 大量模擬，以尋找固定最佳解與平衡問題。

## 3. 對局架構

- **核心人數：** 3～4 人；4 人是規則與平衡的基準人數。
- **對局長度：** 6 回合。
- **起始現金：** 每名玩家 1000 G。
- **勝利條件：** 第 6 回合完成全部結算後，總財富最高者獲勝。
- **每回合航運名額：** 每名玩家最多參與一艘船，無論該船為獨資或合資。
- **商船供給：** 不限；每名玩家每回合皆可出航。

2 人模式是支援方向，不是目前完整定案的核心模式；所需的中立船與其互動規則為**待驗證／暫定**，見 [open-questions.md](open-questions.md)。平手處理、總財富的資產估值方式與資產取得限制亦為待驗證／暫定。

## 4. 資訊公開與隱藏

| 資訊 | 狀態與可見性 |
| --- | --- |
| 各玩家現金 | 公開。 |
| 市場事件 | 每回合開始時公開。 |
| 合資提案與回應 | 公開。 |
| 本回合出航的船隻 | 投資與航運階段結束時公開：每艘船為獨資或合資、屬於哪些玩家，以及哪些玩家不出航。 |
| 角色部署與目標 | 秘密同時選擇；所有人鎖定後才進入揭露與結算。 |
| 航海事件 | 在角色部署鎖定後才公開。 |
| 原始航行骰值 | 不公開；只有鎖定該船的情報商人能在其結算時查看。 |
| 情報商人重擲 | 公開「哪艘船被重擲」；原始骰值與新骰值皆不公開，其他玩家最後只看到沉沒或抵達。 |

各資產持有資訊的完整公開時點為**待驗證／暫定**。

## 5. 每回合流程

V0.6 採用雙階段事件系統。市場事件在投資前公開，航海事件則在角色部署完成後才揭露。

1. **公開市場事件：** 揭露本回合的公開市場條件。
2. **投資與航運：** 玩家依市場條件處理資產相關選擇，並以獨資或合資方式決定出航。
3. **秘密部署角色：** 所有玩家同時選擇角色與必要目標；選擇一旦鎖定，不能因後續資訊回頭變更。
4. **公開航海事件：** 在所有角色部署鎖定後揭露本回合的航海條件。
5. **角色揭露與航程結算：** 依第 7 節的順序處理角色、事件修正與船隻結果。
6. **收益、走私與資產結算：** 發放已定案的航運收益，並處理走私與資產觸發；未定義的效果不可結算。
7. **回合結束：** 進入下一回合；第 6 回合後比較總財富。

市場事件用來改變投資、合作與攻擊誘因；航海事件用來在角色部署後引入航程不確定性。**不使用下一回合市場事件預告。**

## 6. 投資與合作

### 獨資船

單一玩家承擔商船的成本與風險，成功時獨享收益。市場事件可在特定回合提高獨資誘因。

- 出航成本：**100 G**。
- 成功抵達收入：**300 G**。
- 基礎航行判定：擲 **1d6**；最終骰值為 **1～3** 時沉沒，**4～6** 時成功抵達。

角色與事件可以修正航行結果；必須依第 7 節的修正順序，並在最後將結果 Clamp 至 1～6 後再判定。

### 合資

兩名玩家共同投資同一艘船，成功時依規則分配收益。市場事件可提供合資成功時的額外收入；合資的價值也會受雙方資產與秘密角色部署影響。

- 合資船占用兩名股東各自本回合唯一的航運名額。
- 合資船在資產觸發上算作**一艘船**，不是兩艘。
- 股東不得以自己的打撈公司打撈自己持股的合資船。
- 出航成本：**200 G**，兩名股東各出 **100 G**。
- 成功抵達收入：**700 G**，兩名股東各得 **350 G**。
- 出資與收益一律均分；市場事件等對「總收入」的加成同樣由雙方均分。不同比例的合資屬於第 11 節的擴充方向。
- 航行判定與獨資船相同（第 7 節）。

### 合資邀請流程

每回合的「投資與合資邀請」階段依下列步驟進行。

1. **提案（同時、公開）**：每名玩家同時選擇「邀請一名其他玩家合資」或「不發出邀請」，所有提案一併公開。
2. **互邀成立**：兩名玩家互相邀請對方時，合資直接成立。
3. **回應（同時、公開）**：尚未成立合資、且在提案步驟選擇「不發出邀請」的玩家，可從收到的邀請中接受至多一個；接受後合資成立。
   - 發出邀請的玩家不得接受他人的邀請，只能等待對方回應。因此，向「已發出邀請且未互邀成立」的玩家發出的邀請必然不會成立。
   - 未被接受的邀請視為遭拒。
4. **未配對者選擇（同時）**：未成立合資的玩家，選擇「獨資出航」或「不出航」。「不出航」只能在此步驟選擇，不能在提案步驟預先宣告。

選擇不出航的玩家不支付航運成本，也沒有航運收入，仍可部署角色。最終選擇於投資與航運階段結束時公開（見第 4 節）。資產是否能提供或限制合資能力為**待驗證／暫定**項目，詳見 [open-questions.md](open-questions.md)。

### 成本支付與資金限制

- 所有航運成本於合資邀請流程步驟 4 完成後立即支付；沉沒時已支付的成本不退還。
- 玩家不能選擇自己付不起的選項：現金低於合資出資額（100 G）者，不能發出或接受合資邀請；現金低於獨資成本（100 G）者，不能獨資出航。資金不足的玩家仍可選擇不出航。

## 7. 航行骰值與角色

### 航行修正順序

對每艘出航的船依以下順序處理：

1. 擲原始 **1d6** 航行骰。
2. 處理情報商人。
3. 處理護衛。
4. 處理海盜；同一艘船被多名海盜鎖定時，同時處理，不存在搶先順序。
5. 套用事件修正。
6. 將結果 Clamp 至 **1～6**。
7. 最終值 1～3 為沉沒；4～6 為成功抵達。

角色的加減值見下方「核心角色」；角色不會直接造成沉沒，一律透過骰值修正判定。事件修正的完整卡池為**待驗證／暫定**。

### 角色部署規則

- 每名玩家每回合最多部署一個角色，也可以不部署。
- 四種角色皆可由多名玩家在同一回合同時選擇。
- 部署成本：**海盜 100 G**；情報商人、護衛、走私商人各 **50 G**；不部署不需付費。
- 角色可在連續回合重複使用；個別角色的額外使用限制於該角色規則中定義。
- 部署費於部署鎖定時檢查：現金不足以支付者不能選擇該角色。實際扣款在角色揭露時進行，以免公開的現金變動洩漏角色；部署鎖定後至角色揭露前現金不會變動，因此扣款必定成功。角色效果未達成時不退費。

### 核心角色

| 角色 | 已定案能力與限制 | 待驗證／暫定，禁止補完 |
| --- | --- | --- |
| 情報商人 | 鎖定任一艘本回合出航的船。在航海事件公開後、其他角色揭露前，查看該船原始航行骰值並選擇是否重擲；因此做決定時只知道原始骰值與航海事件，不知道其他玩家部署的角色。若重擲，**必須接受新結果**，不得改回舊值，也不得回頭更換角色部署。多名情報商人鎖定同一艘船時，所有人看到同一原始骰值並同時決定；只要有任一人選擇重擲，該船重擲一次。 | — |
| 護衛 | 在情報商人之後、海盜之前處理，定位為保護船隻。鎖定任一艘本回合出航的船（包括自己未參與的船），該船航行骰值 **+2**。多名護衛鎖定同一艘船時效果疊加（每名 +2）。 | — |
| 海盜 | 以攻擊船隻、造成沉沒與取得戰利品為定位；同一目標的多名海盜同時處理。鎖定一艘本回合出航的船，每名海盜使該船航行骰值 **−2**（疊加）。可鎖定自己參與的船，包括背叛合資夥伴。被鎖定的船最終沉沒時即為擊沉成功，戰利品 **150 G** 由銀行支付，由鎖定該船的所有海盜均分，無條件捨去至整數 G。 | — |
| 走私商人 | 與高風險航運的額外獲利相關。使用限制：只能用於自己參與的船，因此本回合未出航者不能部署。該船成功抵達時，走私商人本人額外獲得 **100 G**（不與合資夥伴分配）；沉沒時沒有額外收益。無回合使用限制，可連續部署。於第 5 節步驟 6 結算。 | — |

多名海盜攻擊同一艘船時同時處理，不以玩家順序決定先後；戰利品依上表均分。市場事件「黑市懸賞令」的 +100 G 視為該船戰利品增加 100 G（150 → 250 G），同樣由所有擊沉該船的海盜均分。

## 8. 資產

MVP 的資產類型固定為四種：造船廠、航運保險、打撈公司、貿易交易所。它們的設計目的，是讓資產持有與合作對象、角色部署產生互動，而非只是固定加分。

| 資產 | 已確認定位／限制 | 待驗證／暫定，禁止補完 |
| --- | --- | --- |
| 造船廠 | 與造船或出航成本的合作價值相關。 | 購買成本、效果數值、觸發上限、是否提供合資能力。 |
| 航運保險 | 與航運風險降低或損失補償相關。 | 購買成本、觸發條件、補償數值、V0.6 新保險提案是否採用。 |
| 打撈公司 | 與沉船後的打撈收益相關；持有者不可打撈自己持股的合資船。 | 購買成本、可打撈的船與持有人範圍、觸發上限、一般收益。 |
| 貿易交易所 | 與商船貨物售價或貿易收益相關。 | 購買成本、效果數值、適用於獨資或合資的範圍與觸發上限。 |

市場事件「打撈業繁榮」曾明示把單次打撈收益由 60 G 調為 120 G；但打撈公司的完整正常觸發規則尚未保存，因此不能只憑該事件自行推導實作。

## 9. 市場事件

市場事件在投資前公開。事件應提供誘因、改變策略，而非強制玩家採取單一行動。

| 事件 | 效果 | 策略意圖 |
| --- | --- | --- |
| 皇家聯合訂單 | 合資船成功時，總收入額外增加 200 G。 | 提高合資誘因。 |
| 私人貿易特許 | 獨資船成功時，額外獲得 100 G。 | 提高獨資誘因。 |
| 黑市懸賞令 | 海盜成功造成沉船時，額外獲得 100 G。 | 提高攻擊誘因。 |
| 海域危險警報 | 所有船隻航行判定 -1。 | 提高護衛與保險的價值。 |
| 奢侈品熱潮 | 所有成功抵達的商船，總收入增加 100 G。 | 提高貿易與防禦的潛在價值。 |
| 打撈業繁榮 | 打撈公司的每次收益由 60 G 提高至 120 G。 | 改變打撈與海盜的相對價值。 |

事件卡池組成、抽取方式、是否可重複與各數值的平衡驗證仍待處理。

## 10. 航海事件與結算

航海事件在秘密角色部署完成後公開，保留航運結果的不確定性。它在第 7 節的角色效果後，於事件修正步驟影響航程。其卡池、具體效果與和市場事件的疊加細節為**待驗證／暫定**；不得將市場事件的公開時點、航海事件的揭露時點或兩者的職責混為一談。

## 11. MVP 驗證與實作邊界

MVP 優先驗證 3～4 人對局，可支援 1 名真人玩家搭配 Bot，也必須能執行全 Bot 對局。實作必須符合以下邊界：

- 規則引擎與 UI 分離；引擎只根據規則與行動推進，不依賴瀏覽器介面。
- 所有隨機性經由可注入的 seeded `Rng`；以固定 seed 與行動紀錄可完整重現對局。
- 支援批量 Bot 模擬，並可替換不同策略的 Bot。
- Bot 與 UI 都只能取得該玩家可見的資訊，不能讀取隱藏部署或完整內部狀態。

MVP 先驗證下列問題：

1. 市場事件是否真的改變獨資與合資比例。
2. 玩家是否會因對手資產改變合作與角色部署。
3. 合資是否形成值得承擔風險的合作關係。
4. 是否存在固定最佳策略，或有某事件／資產／角色顯著失衡。

MVP 驗證後才考慮的擴充方向：

- 資產與合資專精。
- 秘密交易、護航、襲擊與情報委託。
- 擴充角色池與特殊能力。
- 不同比例的合資、玩家間保險與附條件收益分配。
- 玩家主動影響市場條件的市場操縱機制。

在上述項目確認前，不應把它們加入 V0.6 的核心規則或 MVP 範圍。複雜合約、自由議價與下一回合市場事件預告則屬於已否決／暫緩項目，沿革見 [changelog.md](changelog.md)。
