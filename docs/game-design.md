# 黑市商會｜V0.6 當前規則快照

**狀態：** gameplay 唯一有效規則來源（Current Rules Snapshot）
**適用範圍：** V0.1～V0.6 之中仍有效、且已有明確紀錄的規則。
**不屬於本文件的內容：** 標示為「**待驗證／暫定**」的項目，包含尚未拍板、數值待平衡或原始細節未保存的提案，統一列於 [open-questions.md](open-questions.md)。該文件不是規則來源，不能據此實作或推定規則。

本文件刻意不把「曾討論過」等同於「已定案」。若本文件沒有明定數值、目標或結算結果，該項目就是未定案；不得以設計意圖、舊摘要或 `open-questions.md` 補完。

## 1. 遊戲概念

《黑市商會》是 2–4 人商業、航運與心理博弈策略遊戲。玩家經營商會資產、投資商船，並在每回合的市場條件下選擇獨資或與其他玩家合資。所有人再秘密部署角色，以護衛、情報、走私或海盜行動影響航運結果與收益分配。

遊戲的核心不是單純最大化航運收入，而是在公開市場資訊與有限的對手資訊下，判斷誰值得合作、誰可能背叛，以及是否應為高收益承擔風險。

## 2. 核心設計目標

- 讓市場事件改變玩家當回合的投資、合作與攻擊意圖。
- 讓獨資與合資各自具有合理的風險／報酬定位。
- 讓秘密角色部署形成可推測、但無法完全掌握的心理博弈。
- 讓資產改變合作對象與角色選擇的價值，而非只是被動加分。
- 保持規則可供 Bot 大量模擬，以尋找固定最佳解與平衡問題。

## 3. 對局架構

- **核心人數：** 3～4 人；4 人是規則與平衡的基準人數。
- **對局長度：** 6 回合。
- **起始現金：** 每名玩家 1000 G。
- **勝利條件：** 第 6 回合完成全部結算後，總財富最高者獲勝（總財富計算見第 8 節）。總財富相同時，現金較多者獲勝；現金也相同時並列獲勝。
- **每回合航運名額：** 每名玩家最多參與一艘船，無論該船為獨資或合資。
- **商船供給：** 不限；每名玩家每回合皆可出航。

2 人模式是支援方向，不是目前完整定案的核心模式；所需的中立船與其互動規則為**待驗證／暫定**，見 [open-questions.md](open-questions.md)。

## 4. 資訊公開與隱藏

| 資訊 | 狀態與可見性 |
| --- | --- |
| 各玩家現金 | 公開。 |
| 市場事件 | 每回合開始時公開。 |
| 資產持有 | 公開；當回合新購買結果於合資招募前公開。 |
| 合資招募、應徵與挑選結果 | 公開。 |
| 本回合出航的船隻 | 投資與航運階段結束時公開：每艘船為獨資或合資、屬於哪些玩家，以及哪些玩家不出航。 |
| 角色部署與目標 | 秘密同時選擇並鎖定；於第 5 節步驟 5 一次全部公開（角色與目標）。**走私商人例外**：揭露時顯示為未部署，只有被查獲時才公開身分（見第 7 節走私結算）。 |
| 黑錢（走私收益） | 只有本人知道；第 6 回合結算後才公開並併入現金。 |
| 船被走私的金額 | 公開（哪艘船被走私、共被取走多少），但不公開走私者。 |
| 航海事件 | 在角色部署鎖定後才公開。 |
| 原始航行骰值 | 部署與揭露期間不公開；只有鎖定該船的情報商人能在部署時查看。重擲時，該情報商人也能看到新骰值。被重擲船的原始骰值永遠只有鎖定該船的情報商人知道。 |
| 情報商人重擲 | 角色公開時一併公開「哪艘船被重擲」。重擲前的原始骰值不對其他玩家公開。 |
| 結算起始骰值與修正 | 角色揭露後、判定各船結果前公開：每艘船結算採用的起始骰值（被重擲的船以重擲後的新值為準）、護衛／海盜／事件各步驟的修正合計，以及 Clamp 後的最終值。 |

規則不限制玩家之間的口頭交流（例如連線時的語音）。情報商人可自行決定是否向其他玩家透露所知的骰值；遊戲本身在結算前不會替玩家公開這些資訊（結算時公開的內容見上表「結算起始骰值與修正」）。

各資產持有資訊公開；每回合的新購買結果於合資招募前公開（見第 8 節）。

## 5. 每回合流程

V0.6 採用雙階段事件系統。市場事件在投資前公開，航海事件則在角色部署完成後才揭露。

1. **公開市場事件：** 揭露本回合的公開市場條件。
2. **投資與航運：** 玩家依市場條件處理資產相關選擇，並以獨資或合資方式決定出航。
3. **秘密部署角色：** 出航船隻公開後，每艘船擲原始 **1d6** 航行骰（不公開）。所有玩家同時選擇角色與必要目標；情報商人於此時查看目標船的原始骰值並決定是否重擲。選擇一旦鎖定，不能因後續資訊回頭變更。
4. **公開航海事件：** 在所有角色部署鎖定後揭露本回合的航海條件。
5. **角色揭露與航程結算：** 一次公開所有玩家的角色與目標並扣除部署費，再依第 7 節的順序套用效果、事件修正並判定船隻結果。UI 可依行動順序逐一演出，但規則上為同時公開。
6. **收益、走私與資產結算：** 依下列順序發放收益（各項收益皆為獨立加總，順序主要用於呈現）：
   1. 走私：抵達的船上，未被查獲的走私商人先從該船航運收入中取走走私貨價值（存為黑錢）；被查獲的走私貨由查獲的護衛均分並公開走私者（見第 7 節）。
   2. 航運收入：扣除走私後的剩餘收入，加上市場事件加成與貿易交易所的合資加成，由船東均分。
   3. 海盜戰利品：含市場事件「黑市懸賞令」加成，以及被搶走的走私貨。
   4. 航運保險的沉沒補償。
   5. 打撈公司。
   6. 貿易交易所的個人效果。

   角色部署費已於步驟 5 角色揭露時扣除。
7. **回合結束：** 進入下一回合；第 6 回合後比較總財富。

市場事件用來改變投資、合作與攻擊誘因；航海事件用來在角色部署後引入航程不確定性。**不使用下一回合市場事件預告。**

## 6. 投資與合作

### 獨資船

單一玩家承擔商船的成本與風險，成功時獨享收益。市場事件可在特定回合提高獨資誘因。

- 出航成本：**100 G**。
- 成功抵達收入：**300 G**。
- 基礎航行判定：擲 **1d6**；最終骰值為 **1～3** 時沉沒，**4～6** 時成功抵達。

角色與事件可以修正航行結果；必須依第 7 節的修正順序，並在最後將結果 Clamp 至 1～6 後再判定。

### 合資

兩名玩家共同投資同一艘船，成功時依規則分配收益。市場事件可提供合資成功時的額外收入；合資的價值也會受雙方資產與秘密角色部署影響。

- 合資船占用兩名股東各自本回合唯一的航運名額。
- 合資船在資產觸發上算作**一艘船**，不是兩艘。
- 股東不得以自己的打撈公司打撈自己持股的合資船。
- 出航成本：**200 G**，兩名股東各出 **100 G**。
- 成功抵達收入：**700 G**，兩名股東各得 **350 G**。
- 出資與收益一律均分；市場事件等對「總收入」的加成同樣由雙方均分。不同比例的合資屬於第 11 節的擴充方向。
- 航行判定與獨資船相同（第 7 節）。

### 合資邀請流程

每回合的「投資與合資邀請」階段依下列步驟進行。

1. **發起招募（同時、公開）**：每名玩家同時選擇「發起合資招募」或「不發起」。招募不指定對象，所有招募一併公開。
2. **應徵（同時、公開）**：每名玩家可從他人的公開招募中應徵至多一個，或不應徵；發起人也可以應徵其他發起人的招募。
   - 發起人一旦應徵他人，就撤回自己的招募，原本應徵他的玩家視為遭拒。
   - 兩名發起人互相應徵時，合資直接成立，兩人都視為發起人（見第 8 節合資加成）。
   - 應徵一名已撤回招募的發起人，視為遭拒。
3. **挑選（同時、公開）**：每名招募仍有效的發起人，從應徵自己且尚未成立合資的玩家中挑選至多一人，合資成立；也可以一人都不選。未被挑選的應徵者與無人應徵的發起人皆未成立合資。
4. **未配對者選擇（同時）**：未成立合資的玩家，選擇「獨資出航」或「不出航」。「不出航」只能在此步驟選擇，不能在招募步驟預先宣告。

選擇不出航的玩家不支付航運成本，也沒有航運收入，仍可部署角色。最終選擇於投資與航運階段結束時公開（見第 4 節）。資產不提供、也不限制合資能力（見第 8 節）。

### 成本支付與資金限制

- 所有航運成本於合資邀請流程步驟 4 完成後立即支付；沉沒時已支付的成本不退還。
- 玩家不能選擇自己付不起的選項：現金低於自己在該合資船應付的出資額（套用造船廠效果後）者，不能發起招募、應徵或被挑選；現金低於獨資成本（100 G）者，不能獨資出航。資金不足的玩家仍可選擇不出航。

## 7. 航行骰值與角色

### 航行修正順序

對每艘出航的船依以下順序處理：

1. 原始 **1d6** 航行骰（已於角色部署階段擲出）。
2. 情報商人的重擲（已於角色部署時決定並執行）。
3. 處理護衛：每名鎖定該船的護衛使該船 +1（航運保險持有者的護衛 +2）。
4. 處理海盜：每名鎖定該船的海盜使該船 −1；同一艘船被多名海盜鎖定時，同時處理，不存在搶先順序。
5. 套用事件修正（市場事件與航海事件的骰值修正相加）。
6. 將結果 Clamp 至 **1～6**。
7. 最終值 1～3 為沉沒；4～6 為成功抵達。

角色的加減值見下方「核心角色」；角色不會直接造成沉沒，一律透過骰值修正判定。事件修正見第 9、10 節。

### 角色部署規則

- 每名玩家每回合最多部署一個角色，也可以不部署。
- 四種角色皆可由多名玩家在同一回合同時選擇。
- 部署成本：**海盜 100 G**；情報商人、護衛各 **50 G**；走私商人 **0 G**；不部署不需付費。
- 角色可在連續回合重複使用；個別角色的額外使用限制於該角色規則中定義。
- 部署費於部署鎖定時檢查：現金不足以支付者不能選擇該角色。實際扣款在角色揭露時進行，以免公開的現金變動洩漏角色；部署鎖定後至角色揭露前現金不會變動，因此扣款必定成功。角色效果未達成時不退費。

### 核心角色

| 角色 | 已定案能力與限制 | 待驗證／暫定，禁止補完 |
| --- | --- | --- |
| 情報商人 | 鎖定任一艘本回合出航的船。於角色部署時查看該船原始航行骰值並當場決定是否重擲；做決定時不知道本回合航海事件，也不知道其他玩家部署的角色。若重擲，**必須接受新結果**，不得改回舊值，也不得回頭更換角色部署。多名情報商人鎖定同一艘船時，所有人看到同一原始骰值並於部署時同時決定；只要有任一人選擇重擲，該船重擲一次。 | — |
| 護衛 | 在情報商人之後、海盜之前處理，定位為保護船隻與查緝走私。鎖定任一艘本回合出航的船（包括自己未參與的船），每名護衛使該船航行骰值 **+1**（疊加）。船抵達時可查獲走私（見「走私結算」）。 | — |
| 海盜 | 以攻擊船隻、造成沉沒與取得戰利品為定位；同一目標的多名海盜同時處理。鎖定一艘本回合出航的船，每名海盜使該船航行骰值 **−1**（疊加）。可鎖定自己參與的船，包括背叛合資夥伴。被鎖定的船最終沉沒時即為擊沉成功，戰利品 **150 G** 由銀行支付，由鎖定該船的所有海盜均分，無條件捨去至整數 G。 | — |
| 走私商人 | 匿名的高風險獲利。任何玩家（包括未出航者）都可鎖定任一艘本回合出航的船，但不能鎖定自己的獨資船。揭露時顯示為未部署。船上帶有價值 **50 G** 的走私貨，結算方式見下方「走私結算」。無回合使用限制，可連續部署。部署費必須為 0，否則公開扣款會洩漏身分。 | — |

多名海盜攻擊同一艘船時同時處理，不以玩家順序決定先後；戰利品依上表均分。市場事件「黑市懸賞令」的 +100 G 視為該船戰利品增加 100 G（150 → 250 G），同樣由所有擊沉該船的海盜均分。

### 走私結算

走私商人鎖定的船上帶有一批走私貨，價值 **50 G**（航海事件「黑市熱絡」時為 150 G）。依船的結果結算：

| 情況 | 走私貨的下場 |
| --- | --- |
| 船抵達，且有走私商人本人以外的護衛鎖定該船（包括船東） | **查獲**：走私者身分公開，並向銀行支付罰款 **200 G**（現金不足時付出全部現金，黑錢不能用來繳罰款）；走私貨價值由銀行支付，由所有鎖定該船的護衛均分，無條件捨去至整數 G。航運收入照常均分。 |
| 船抵達，未被查獲 | 走私商人先從該船的**基本航運收入**中取走走私貨價值，存為只有本人知道的**黑錢**；公開「該船被走私多少」但不公開走私者。剩餘收入再加上各項收入加成後由船東均分。 |
| 船沉沒，且有海盜鎖定該船 | **搶走**：走私貨價值由銀行支付，由所有鎖定該船的海盜均分（無條件捨去），另計原本的戰利品。 |
| 船沉沒，沒有海盜 | 走私貨隨船沉沒，無人取得。 |

- 護衛只在船抵達時查獲；船沉沒時，未被查獲的走私貨可被海盜搶走。
- 船沉沒時，走私者身分不公開（包括被海盜搶走時）。
- 多名走私商人鎖定同一艘船時，各自帶有一批走私貨，分別結算。未被查獲且走私貨總值超過基本航運收入時，基本航運收入由這些走私商人均分（無條件捨去），不再有剩餘；收入加成仍由船東均分。
- 黑錢不能在對局中花用，第 6 回合結算後公開並併入現金。
- 走私貨價值必須為偶數，使合資船扣除走私後的收入仍可由兩名船東均分。
- 例：合資船抵達（基本收入 700 G），一名第三方走私商人未被查獲：走私商人取走 50 G 黑錢，剩餘 650 G 由兩名船東均分，各得 325 G。

## 8. 資產

MVP 的資產類型固定為四種：造船廠、航運保險、打撈公司、貿易交易所。它們的設計目的，是讓資產持有與合作對象、角色部署產生互動，而非只是固定加分。

### 資產取得規則

- 購買時點：每回合「投資與航運」階段開頭、合資招募之前。所有玩家同時決定是否購買，購買結果公開後才進入合資邀請流程；購入的資產當回合即生效。
- 每回合每名玩家最多購買一張資產。
- 每名玩家每種資產最多持有一張；資產供給不限，不會因他人購買而售罄。
- 資產持有資訊公開。

- 購買價格於購買時立即支付；現金不足以支付者不能購買。

| 資產 | 購買價格 | 效果 |
| --- | ---: | --- |
| 造船廠 | 300 G | 持有者本人每次航運成本 −50 G（獨資 100 → 50 G；合資時本人出資 100 → 50 G，不影響夥伴的出資）。 |
| 航運保險 | 300 G | 持有者投資的船沉沒時，持有者獲得 150 G，每回合最多 1 次。另外，持有者部署的護衛效果 **+1**（該護衛為 +2）。 |
| 打撈公司 | 400 G | 其他玩家的船沉沒時，持有者每艘獲得 60 G，每回合最多 2 次。持有者參與的船（包括自己持股的合資船）不觸發。 |
| 貿易交易所 | 400 G | 其他玩家的船成功抵達時，持有者每艘獲得 40 G，每回合最多 2 次。持有者參與的船不觸發。 |

- 上表效果只影響持有者本人，不與合資夥伴分享。

### 合資加成

合資船的發起人（發起招募者）持有下列資產時，該合資船另外獲得合資加成。只有發起人的資產提供合資加成；應徵者的資產只提供上表的個人效果。兩名發起人互相應徵而成立的合資船，兩人都視為發起人，兩人的資產加成都適用，但同一種資產只計算一次、不疊加。

| 資產 | 合資加成 |
| --- | --- |
| 造船廠 | 應徵者的出資也 −50 G（發起人本人的出資已由個人效果 −50 G，整艘船成本 200 → 100 G）。應徵者自己也持有造船廠時不疊加，其出資最多 −50 G。 |
| 貿易交易所 | 合資船成功抵達時，總收入 +100 G，由雙方均分。 |
| 航運保險 | 無。沉沒補償只由持有者本人獲得。 |
| 打撈公司 | 無。 |

- 合資船在打撈公司、貿易交易所的觸發上算作一艘船。
- 市場事件「打撈業繁榮」使打撈公司每次收益由 60 G 提高至 120 G，每回合 2 次的上限不變。
- 資產不提供、也不限制合資能力。

### 最終財富

第 6 回合結算後，先將所有玩家的黑錢公開併入現金，總財富 = 現金 + 持有資產購買價格的一半（造船廠、航運保險各計 150 G，打撈公司、貿易交易所各計 200 G）。

## 9. 市場事件

市場事件在投資前公開。事件應提供誘因、改變策略，而非強制玩家採取單一行動。

| 事件 | 效果 | 策略意圖 |
| --- | --- | --- |
| 皇家聯合訂單 | 合資船成功時，總收入額外增加 200 G。 | 提高合資誘因。 |
| 私人貿易特許 | 獨資船成功時，額外獲得 100 G。 | 提高獨資誘因。 |
| 黑市懸賞令 | 海盜成功造成沉船時，額外獲得 100 G。 | 提高攻擊誘因。 |
| 海域危險警報 | 所有船隻航行判定 -1。 | 提高護衛與保險的價值。 |
| 奢侈品熱潮 | 所有成功抵達的商船，總收入增加 100 G。 | 提高貿易與防禦的潛在價值。 |
| 打撈業繁榮 | 打撈公司的每次收益由 60 G 提高至 120 G。 | 改變打撈與海盜的相對價值。 |

### 市場事件牌庫

- 上表 6 種事件各 2 張，共 12 張。
- 對局開始時以 seeded `Rng` 洗牌；每回合開始時抽 1 張並公開，抽過的牌不放回。整局抽 6 張，因此同一事件最多出現 2 次，也可能有事件不出現。

## 10. 航海事件與結算

航海事件在秘密角色部署完成後公開，保留航運結果的不確定性。骰值類效果於第 7 節修正順序的「套用事件修正」步驟生效；收益類效果於收益結算時生效。不得將市場事件的公開時點、航海事件的揭露時點或兩者的職責混為一談。

| 事件 | 效果 | 類型 |
| --- | --- | --- |
| 順風 | 所有船 +1。 | 全體骰值修正 |
| 暴風雨 | 所有船 −1。 | 全體骰值修正 |
| 海霧 | 被海盜鎖定的船 +1。 | 與角色互動 |
| 月黑風高 | 被護衛鎖定的船 −1。 | 與角色互動 |
| 巨浪 | 獨資船 −1。 | 依船的類型 |
| 黑市熱絡 | 走私貨價值由 50 G 提高至 150 G。 | 影響收益 |
| 風平浪靜 | 無效果。 | — |

- 「被某角色鎖定的船」類效果，不論該船被幾名該角色鎖定，都只計算一次。
- 情報商人於角色部署時就決定是否重擲，無法參考本回合航海事件。

### 航海事件牌庫

- 上表前 6 種事件各 2 張，「風平浪靜」2 張，共 14 張。
- 抽取規則與市場事件相同：對局開始時以 seeded `Rng` 洗牌，每回合於角色部署鎖定後抽 1 張並公開，不放回。

### 事件修正的疊加

市場事件與航海事件的骰值修正在修正順序的「套用事件修正」步驟相加，最後再 Clamp 至 1～6。例如「海域危險警報」−1 與「暴風雨」−1 同時生效時為 −2。

## 11. MVP 驗證與實作邊界

MVP 優先驗證 3～4 人對局，可支援 1 名真人玩家搭配 Bot，也必須能執行全 Bot 對局。實作必須符合以下邊界：

- 規則引擎與 UI 分離；引擎只根據規則與行動推進，不依賴瀏覽器介面。
- 所有隨機性經由可注入的 seeded `Rng`；以固定 seed 與行動紀錄可完整重現對局。
- 支援批量 Bot 模擬，並可替換不同策略的 Bot。
- Bot 與 UI 都只能取得該玩家可見的資訊，不能讀取隱藏部署或完整內部狀態。

MVP 先驗證下列問題：

1. 市場事件是否真的改變獨資與合資比例。
2. 玩家是否會因對手資產改變合作與角色部署。
3. 合資是否形成值得承擔風險的合作關係。
4. 是否存在固定最佳策略，或有某事件／資產／角色顯著失衡。

MVP 驗證後才考慮的擴充方向：

- 資產與合資專精。
- 秘密交易、護航、襲擊與情報委託。
- 擴充角色池與特殊能力。
- 不同比例的合資、玩家間保險與附條件收益分配。
- 玩家主動影響市場條件的市場操縱機制。

在上述項目確認前，不應把它們加入 V0.6 的核心規則或 MVP 範圍。複雜合約、自由議價與下一回合市場事件預告則屬於已否決／暫緩項目，沿革見 [changelog.md](changelog.md)。
