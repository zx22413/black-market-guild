# 新手教學｜形式與內容大綱（草稿）

**狀態：** 討論中的草稿，**不是規則來源**。所有規則與數值以 [game-design.md](game-design.md)（V0.7）為準；本文只決定「怎麼教、教什麼、依什麼順序」。規則改動時先改 game-design.md，再回頭調整本文與教學腳本。

## 1. 形式決議

- **教學本體是「host 帶領的引導對局」**：固定 seed、腳本化 Bot 對手、在指定步驟鎖住合法行動，由遊戲內的 NPC host（文字氣泡＋立繪）講解。
- **先做 NPC 模式**，玩家做完該步動作才往下。
- **真人 host 模式（之後再加）**：同一份步驟清單，改由房主按「上一步／下一步」推進，全房同步高亮；步驟資料需把「完成條件」與「文案／聚焦目標」分開存放，之後加入時不必重寫。真人 host 模式下無法鎖住對手行動，只能高亮加說明。
- **語音、旁觀教練座位、指點工具（ping）不做**，語音交給外部工具。
- 新手去找別人玩：**建議、不強制**先走過單人教學；房內局內提示另案。
- host 先用**文字氣泡＋立繪**，不配音（規則仍在調整，配音每次改規則都要重錄）。
- 教學結束**回主選單**。
- 教學可以**跳過、重玩**。
- **進度保存與中間進入（暫定，待確認）：** 只記「各部分是否完成」（本機即可，不用伺服器），不記對局中途進度。
  - 角色部分的小情境彼此獨立，從選單可任選一個進入、重玩。
  - 基礎引導對局是連續的一局，只能從頭開始；中途離開就下次重來（約 10 分鐘，可接受）。

## 2. 結構

| 部分 | 內容 | 預估長度 | 必修 |
| --- | --- | --- | --- |
| 基礎 | 引導對局 3 回合：骰子、買賣、貨物、建築 | 8～10 分鐘 | 是 |
| 角色 | 護衛、海盜、情報商人、走私商人（含軍火掩護），預設局面的小情境 | 約 7～8 分鐘 | 是 |
| 進階 | 莊家、選島 | 各 1～2 分鐘，自己點 | 否 |

通緝令與排行不另立步驟，順著主線帶出（見第 4 節）。

- 小情境直接跳進預設好的局面（不必從第 1 回合打起），一個目標、一個選擇、做完立刻結算。
- 全程在畫面一角顯示目前的回合階段（投資、部署、重擲、事件、揭露、結算、黑市），不另花一步講。
- 4 人局（規則基準人數），3 個腳本化 Bot。

## 3. 必須先講的觀念

- **同時、秘密提交**：每個決定階段所有人同時選、同時揭露（game-design 第 4、5 節）。第一次投資階段就講。
- **資訊公開與隱藏**：船上裝什麼貨保密到結算；**原始航行骰值也是秘密**，連船東自己都不知道，結算才公開（只有看過該船的情報商人知道）。因此護衛是機率押注（抵達機率約 50% 提高到約 67%），不是「看到骰值再補救」。
- **價格怎麼動**：到港量對上需求卡，少於漲、等於不變、多於跌；本回合的貨以變動後新價格賣出。

## 4. 基礎：引導對局（教學預設島：林場島）

林場島：木材第 1～5 回合每回合生產（鐵礦只在第 1、4 回合）。選它是因為造船廠要 2 木材，建築教學順手，且木材沒有特殊風險。

**第 1 回合：骰子與賣貨**
1. host 開場：你是島主，1000 G、1 木材、1 鐵礦，6 回合後總財富最高者勝。簡述林場島的優缺點（一句話）。
2. 回合開始自動生產；host 指認需求卡與價格軌。
3. 投資：host 要你裝 1 木材、1 香料出航（只能在這兩樣、各 1 單位以內選），講「同時、秘密」與出航成本。
4. 航海事件公開：風平浪靜（先讓「事件」出現但無效果）。
5. 結算：固定 seed 讓骰值為 5，船抵達；4～6 抵達、1～3 沉沒。到港量對需求，價格變動，貨以新價賣出；第一次帶出航海日記，逐行帶看；同時用一句話帶過畫面上的排行（目前總財富排名）。

**第 2 回合：擠貨與沉船**
0. 回合開始：第 1 回合賺錢後，玩家現金最多而被通緝（第 9.6 節），host 順著介紹——載有通緝者貨物的船被擊沉時海盜戰利品 +100 G；實際效果在海盜情境示範。
1. 腳本讓 Bot 也運木材，到港量超過需求、價格下跌，玩家親眼看到「大家擠同一種貨會崩」。
2. 事件：暴風雨（所有船 −1）。固定 seed 讓原始骰值 4，−1 後為 3，船沉沒——「本來能過，事件後才公開才沉」，體驗出航成本不退、貨全沒。
3. host 順帶介紹香料（放不住）與軍火（賣得貴；沒收風險留到角色部分）。

**第 3 回合：建築與排擠**
1. 事件：順風（所有船 +1）。
2. 教蓋造船廠：host 指出「蓋用掉的木材就不能再裝船」，且每回合可裝貨量只有 3 單位——這就是資源排擠。建造在裝貨之前，當回合生效。
3. 收尾：總財富 = 現金 + 建築成本一半，剩餘材料不計分；預告角色部分。

## 5. 角色：預設局面小情境

| 情境 | 目標 | 要帶到的規則 |
| --- | --- | --- |
| 護衛 | 玩家不知道自己船的骰值，部署護衛押注 +1 | 部署費、機率提升；守別人的船可領護航費；冷卻 2 回合 |
| 海盜 | 鎖定對手的船 −1，沉沒時分戰利品 | 部署費、戰利品；目標是通緝者時加碼 |
| 情報商人 | 看見自己船的骰值為 2，決定是否重擲 | 重擲必須接受新結果；做決定時不知道事件 |
| 走私商人 | 鎖定對手的船夾帶私貨 | 船抵達且無護衛才抽成；有護衛被抓罰款；沉沒遇海盜被搶；不必自己出航 |
| 軍火掩護 | 自己的船載軍火，對手可能派護衛沒收 | 別人的護衛會沒收軍火；自己的走私商人上自己的船可掩護，但不賺錢、不會被罰 |

走私商人是必修（軍火沒收與掩護是新手最容易搞混的規則），所以拆成兩個小情境，各只問一個選擇。

## 6. 航海事件的介紹方式

牌庫 6 種事件各 2 張、共 12 張，每回合抽 1 張、不放回；事件在情報重擲決定後才公開，所以部署時不知道。

- **主線只出現三種**：風平浪靜（第 1 回合，無效果）、暴風雨（第 2 回合）、順風（第 3 回合）。這三種是「所有船 ±1」，不需要先懂角色。
- **三種跟角色有關的，在角色部分各用一句話帶出**：
  - 海霧：被海盜鎖定的船 +1（海盜反而幫了對手）。
  - 月黑風高：被護衛鎖定的船 −1（護衛的 +1 被抵銷）。
  - 黑市熱絡：走私商人的私貨價值由 100 G 提高到 150 G（放進走私商人情境）。
- 角色小情境可以在揭露事件的瞬間安排「意外」，讓玩家感受到「部署時不知道事件」的不確定性。

## 7. 島嶼的介紹方式

- **主線只介紹林場島**，用一句話講優缺點，不在主線說明其他島。
- **進階「選島」小情境**：給玩家 2 座島，讓他體驗「秘密選、同時公開」，並用 host 講每座島改變了什麼打法。
- **島嶼速查卡**（規則頁，不是教學步驟），把 8 座島依打法分三類方便記憶：
  - 產能型：林場島、礦山島、香料群島、走私港（改變生產）
  - 航運型：自由港、燈塔島（改變出航成本與骰值）
  - 對抗型：海盜灣、要塞島（強化海盜或護衛）

## 8. 待確認

- 進度保存與中間進入的暫定做法（第 1 節）待使用者確認。
- 排行的帶出方式（第 1 回合結算時一句話帶過）為暫定，使用者尚無意見。
- 林場島的 seed 與各回合需求卡、Bot 行動腳本需要實際試跑才能定，各步驟的具體數字（現金、價格）尚未決定。第 1 回合結算後玩家要是現金最多者（才會在第 2 回合被通緝），這點也要靠腳本驗證。
- host 的外觀、自動前進與必須手動按的步驟，屬於體驗細節，尚未討論。
- 規則仍在調整（V0.7 尚待搬進正式引擎），教學腳本中的數字應引用規則常數，避免硬編碼。

## 9. 技術評估（2026-10-20，對照 `src/v07`、`src/ui-v07`）

教學建立在 V0.7（`src/v07` 引擎＋Runner、`src/ui-v07` 3D 桌面）上，**不改規則引擎**。

### 9.1 核心原則：只操控「隨機抽出的東西」

UI 的桌面完全由公開事件重建（`session/board.ts`），所以教學**不能直接改現金、倉庫等公開數值**，否則畫面會和引擎對不上。教學只改尚未公開的隨機結果，其他一律由真的行動產生：

| 要固定的東西 | 做法 |
| --- | --- |
| 需求卡、航海事件的順序 | 開局後改寫 `demandDeck`、`voyageDeck`（翻開時才有公開事件） |
| 航行骰值 | 投資階段結束後改寫各船 `rawRoll`（結算才公開；情報商人的私有事件在部署鎖定時才發，會讀到改寫後的值） |
| 情報重擲的新骰值 | 重擲在同一個轉換裡算出並發私有事件，不能事後改；改成重擲前預先設定 `rng` 狀態，讓下一次抽出想要的值 |
| 選島 | 開局時改寫 `islandOffers` 讓玩家拿到林場島，並由腳本自動選，不顯示選島畫面 |
| Bot 的行動 | 腳本化 Controller：每個決定從合法行動中挑出指定的那一個 |
| 鎖住玩家的選擇 | 交給 UI 的 `DecisionContext.legalActions` 先過濾，只留教學要的選項 |

這和 `tests/v07/game/helpers.ts` 的 `playRound`（固定骰值與事件）是同一種手法。

### 9.2 角色小情境怎麼「跳進預設局面」

不從任意狀態開局（桌面沒有事件歷史會壞），而是**快轉**：由腳本代打前面的步驟（包含玩家自己的投資），播放直接跳過，到目標決定才交給玩家。局面的數字都是真的打出來的，畫面一定一致。

### 9.3 要改的地方

| 位置 | 改動 | 規模 |
| --- | --- | --- |
| `src/v07/match/runner.ts` | `runMatch` 加可選的 `stage(state) → state` 掛勾，在每次轉換之間改寫隨機結果；不傳時行為不變 | 小 |
| 新增 `src/v07/tutorial/`（純邏輯） | 教學腳本：各回合的牌序、骰值、Bot 行動、玩家可選的行動、host 步驟資料（觸發條件、文案、聚焦目標、完成條件） | 中 |
| `tests/v07/tutorial/` | 無頭跑完整個教學腳本，驗證預期結果（第 1 回合抵達、第 2 回合木材跌價且船沉、玩家被通緝等）；規則改動讓教學失效時測試會先壞 | 中 |
| `src/ui-v07/session/` | 教學用的 session（接腳本化 Controller 與過濾後的合法行動）；`usePlayback` 加可注入的暫停條件，讓 host 在指定事件前停下講解 | 中 |
| `src/ui-v07/table/investChoice.ts`、`deployChoice.ts` | 被教學鎖住的選項要顯示「教學中先不用」，而不是一般的不能選原因 | 小 |

| `src/ui-v07/App.tsx`、`screens/SetupScreen.tsx` | 主選單加「新手教學」入口、教學結束回主選單；完成進度存本機（同 `reminderSettings.ts` 的 localStorage 做法） | 小 |

### 9.4 風險

- **V0.7 UI 仍在大幅調整**（多數 3D 元件標為試驗），聚焦目標綁 UI 版面，版面一改教學就要跟著改。host 步驟資料只引用穩定的標記名稱，降低耦合。
- 現有的一次性操作提示（`isHintSeen`／`markHintSeen`，如裝貨提示）會和教學重複，教學中要關掉。
- 正式 `vite build` 尚未收錄 `v07.html`，教學上線要等 V0.7 介面正式切換。

## 10. 第一版實作：講解局（2026-10-21 更新）

程式在 `src/v07/tutorial`（腳本）、`src/ui-v07/tutorial`（畫面），入口是開始畫面的「新手教學」。**本節取代第 2、4、5 節的結構**：角色改為做進引導對局，不再分「進階」。

### 10.1 課程

| 分類 | 課程 | 內容 |
| --- | --- | --- |
| 完整教學 | 一整局（6 回合） | 1 出航賣貨 · 2 通緝令、四種貨、暴風雨、擠貨、**護衛** · 3 建築與排擠、冷卻、**海盜**、順風 · 4 **情報商人**與重擲 · 5 **走私商人**、黑市熱絡；Bot 示範軍火沒收與掩護 · 6 **莊家**，最後總財富 |
| 單課重玩：角色 | 護衛、海盜、情報商人、走私商人、軍火掩護、莊家 | 各 1 回合，投資由腳本代打，只做一個角色決定 |
| 開局 | 開局選島 | 林場島與燈塔島 2 選 1，秘密選、同時公開，在第 1 回合開始前結束 |

- 每個角色在一整局裡只用一次，不會撞到冷卻（第 9.3 節）。走私與掩護都用走私商人，所以掩護改由 Bot 示範：凡德商行派護衛守黑潮會的船，黑潮會用自己的走私商人掩護軍火。
- 林場島第 6 回合不產木材，莊家那回合要裝 1 木材，所以第 4、5 回合不能裝木材。
- 第 4、5 回合由 Bot 運木材壓住木材價格，第 6 回合莊家押漲時，指定的船才有空間多漲 2 格。
- 你能選的裝貨組合都經測試確認不會破壞後面的劇情：第 2 回合仍被通緝、第 3 回合仍蓋得起造船廠、第 6 回合莊家仍押對。

### 10.2 推進與聚焦

- 講解卡顯示文字，由操作的人按「下一步」推進。熟人測試時由真人主持、分享畫面講解；同一份文字之後就是 NPC 版。
- **聚焦框**：每一步都指定要亮起的地方（黑市列、某種貨的價格、某座島、名牌、排行、底部操作列、角色手牌、重擲卡、選島卡等），其他地方蓋上黑色遮罩，可以同時亮好幾處。島嶼的框跟著 3D 鏡頭移動。讀完一個決定前的所有講解後，遮罩保留在最後一步的位置，直到你做完決定。
- **讀講解時只能按「下一步」**：每一步講解出現時，桌面都蓋一層透明擋板（決定、「繼續」、「開始航程」都點不到），「下一步」會閃爍；點到桌面時「下一步」會晃一下提示。講解中的聚焦框只框內容，不框可以按的按鈕。
- **操作引導**：讀完講解、輪到你操作時，依序只亮下一個要點的東西，例如護衛是「護衛卡 → 你的船 ＋ → 提交」，裝貨是「木材 → 香料 → 提交」，莊家是「莊家卡 → 木材▲漲 → 你的船 → 提交」。畫面依元素狀態（卡片選了沒、船選了沒、貨箱裝了幾箱）判斷走到哪一步。
- 「還沒做完」這類提醒視窗出現時，聚焦改亮那個視窗。
- 重疊的框合併成一個，框線不會畫過按鈕。
- **價格說明放在市場卡**：第 1、2 回合「價格怎麼動」「大家都運木材」改在結算的市場卡（價格一格一格移動的那張）出現，市場卡會停住，直到講解讀完。
- 講解卡會自動移到不蓋住亮起區域的角落（左上、右上、左下、右下依序試）。
- 部署時船上方的目標按鈕（「派到…的船 ＋」）也算進那座島的聚焦範圍。
- 第 3 回合蓋造船廠：建築清單還沒打開時框「＋ 建築」按鈕，打開後只框造船廠卡片；選了造船廠就算完成，聚焦跳到「提交」（裝不裝貨都可以）。
- **結算中**：講解框航海事件卡和推進結算的按鈕。講解讀完後，畫面在等你按「繼續」「開始航程」或點掉帳單時，自動只亮那顆按鈕並閃爍；沒有按鈕可按時（航程播放中）遮罩自動消失。
- **提交提醒**：你的選擇符合這一步的要求時（例如裝好 1 木材＋1 香料），遮罩改成只亮「提交」按鈕並加上閃爍的光圈，待辦改成「好了，按「提交」」。可以自由選的步驟（例如第 3 回合蓋好造船廠後裝什麼都行），只要選擇合法就算完成。
- 桌面載入完成前不顯示講解。
- **結算中不爆雷**：結算播放時講解卡只提示要看什麼，結果的解釋放在結算播完之後（下一回合開頭，或課程結束時）。

### 10.3 已知限制

- 被教學鎖住的角色卡，顯示的是一般的不能派原因（例如「沒有可選的目標」），不是「這一課先不用」；做 NPC 版前要處理。
- 第 1 回合大家現金相同、沒有人被通緝；整局裡你一直是現金最多的人，所以海盜的通緝加成只在文字中帶到，沒有實際演出。
