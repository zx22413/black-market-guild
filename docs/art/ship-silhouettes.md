# 五艘船的剪影（2026-11-06 使用者定案）

五種船（第 8.1 節）要**靠輪廓分辨，不靠顏色**：顏色留給「誰的船」，剪影負責「哪一種船」（Valve 在 TF2 的作法：陣營用色、職業用剪影）。目標是遊戲實際鏡頭（`TableCanvas` 的 `[0, 82, 60]`，約 54° 俯角）下縮到手機大小（約 20～32 px）仍分得出來。

## 原則

- 先做純黑剪影，沒有內部細節也要認得出來；細節只加在縮小後還留得住的地方。
- 每艘船只靠**一個主要特徵**辨識，五個特徵屬於不同類型，不要兩艘共用同一類特徵。
- 造型可以誇張、卡通化（使用者同意），比例誇張比寫實好認。
- 船頭朝向鏡頭時也分得出來（已在剪影圖確認）。

## 五艘船

| 船 | 參考船型 | 主要特徵（縮小後靠它辨識） | 其他 |
| --- | --- | --- | --- |
| 信天翁號 `standard` | 單桅方帆船 | 一根桅杆＋一面加寬的方帆（像展開的翅膀） | 當「標準形」；船尾小艙、桅頂三角旗 |
| 孤注號 `gambler` | 拉丁帆船（xebec） | 細長船身上一面超大、偏向一側的三角斜帆，桅杆前傾，長船首斜桅 | 帆大到看起來會翻；五艘中唯一的大三角帆 |
| 巨鯨號 `freighter` | 荷蘭 fluyt（17 世紀的大貨船，2026-11-07 改） | 梨形大肚子的寬圓船身（水線附近最寬、往上收窄成窄甲板），藍色上舷＋金色腰帶（漆色 2026-11-07 從綠、炭黑、紅、藍並排比較後選藍） | 三根桅：前、主桅各兩層窄而高的方帆（不像信天翁號一面加寬的單帆），後桅一小面三角帆；又高又窄的船尾艙房＋拱形彩繪尾板（鯨尾）；主帆畫鯨尾紋章；一排金框貨艙口；尖船首＋斜桅 |
| 幽靈號 `hidden` | 鬼船 | 破成垂條、下緣鋸齒的歪斜破帆，前桅斷一截往前折 | 船身低；船尾掛燈籠；**夜晚破帆與燈籠發青綠色光** |
| 海嘯號 `breaker` | 撞角槳帆船（三列槳戰船） | 兩側各一排槳（從上方看像梳子）＋船頭低撞角 | 船尾往上捲；一面小方帆 |

## 試過但不採用

- 巨鯨號做成中式帆船（2026-11-06 的版本，以及 2026-11-07 的風格化中式貨船設計稿）：使用者覺得太中式、帆醜；鯨魚頭船首雕像與船尾鯨尾也不合，改成荷蘭 fluyt（設計稿 `docs/art/freighter-concept.svg`）。

- 幽靈號只有光桅杆、收帆：縮小後看不出是什麼，沒特色。
- 幽靈號披床單（圓頂、波浪下擺、眼洞）：沒選。
- 海嘯號楔形船身＋撞角＋側邊刀刃：看不出是什麼。
- 海嘯號捲浪形的帆：醜。
- 海嘯號外撐架＋蟹螯帆、龍首龜甲船：沒選（蟹螯帆可能和孤注號的三角帆搞混；龜甲的寬橢圓像巨鯨號）。

## 模型與動態（2026-11-06）

模型在 `src/ui-v07/scene/ships/`（說明見 `src/ui-v07/README.md`），預覽在 `/v07.html?dev=ships`。五艘船的船身與甲板佈置都在 Blender 裡做（`scripts/blender/build-<type>.py` 產生 `public/models/ships/<type>.glb`；巨鯨號以外的四艘直接匯入核准的粗模 `blockout-<type>.py` 的幾何，2026-11-07），桅、帆桁、繩索仍取自 `designs.ts`，帆、尾旗、槳、燈火照舊由程式碼畫；帆上紋章（鯨尾、信天翁、浪花）由 `clothMaterial.ts` 畫，孤注號的放射條紋是 `SailSpec.bands` 的 `fan`；幽靈號 GLB 另有 `glow` 網格（舷窗、窗、破洞），月黑風高時發青綠光；網址加 `?codeships` 可看程式碼拼的備用船身。玩家顏色目前只用在桅頂的尾旗；要不要再加到帆或船身尚未決定。

每艘船有自己的循環動態，停在碼頭時慢、出航時快：

| 船 | 動態 |
| --- | --- |
| 信天翁號 | 一隻信天翁繞著桅頂盤旋，碼頭時多滑翔，出航時拍翅較多 |
| 孤注號 | 船尾甲板的大骰子不時跳起翻到另一面；出航時陣風讓船大幅傾斜 |
| 巨鯨號 | 前桅後方的吊桿不時把一個貨箱從甲板一側吊起、轉到另一側放下，停一下再吊回來；船身緩慢地沉重搖晃 |
| 幽靈號 | 破帆飄動，船在沒有浪的地方自己起伏、慢慢傾斜，船尾燈籠搖晃；月黑風高時破帆發青綠光、明暗呼吸，燈籠裡是青綠色的火，船邊有幾團鬼火繞著飄、忽大忽小 |
| 海嘯號 | 上下兩排槳一起划（下排慢一點點），划的時候船頭微微抬起；停在碼頭時槳泡在水裡隨浪輕晃 |

所有帆都會隨風鼓起（出航時更飽滿），尾旗與破布會飄動。帆的邊緣是弧線（下緣往下鼓、兩側略往外鼓，中式帆的後緣是扇形），不是方塊；鼓起的地方用平面著色呈現明暗。燈籠是鐵框，只有裡面的火焰和光暈會亮，白天是沒點的蠟燭。

## 四艘船改版：Blender 粗模設計稿與定案（2026-11-07）

照巨鯨號的做法改版，設計稿改用 Blender 粗模的正投影算繪（`scripts/blender/blockout-<type>.py`，共用 `blockout_kit.py`；標註 `compose-sheet.py` ＋ `docs/art/blockouts/<type>-sheet.json`；稿是 `docs/art/<type>-concept.svg/png`）。使用者確認的設計與待確認的答案：

| 船 | 船型 | 定案 |
| --- | --- | --- |
| 信天翁號 | 中世紀柯克船（cog）：短胖船身、直的斜船首柱與船尾柱、前後兩座木框砂岩城樓＋紅白城垛、桅頂瞭望台 | 帆桁 ±2.6（像展開的翅膀）；城垛紅色用 `roofRed`；拿掉三角前帆，只留一面方帆；兩城樓間甲板約 2.7 長，貨箱位置建模時在選貨畫面實測再調 |
| 孤注號 | 地中海 xebec：細長紅船身、金邊長尖喙、船尾上翹並挑出平台、桅杆前傾 | 帆整面等比縮到帆頂約 7.0；紅白條紋改成從帆角放射的扇形（帆的著色器一起改）；燈籠移到船尾平台尾柱上 |
| 幽靈號 | 風格化鬼船：歪斜帆桁＋鋸齒破帆、前桅斷口往前折、黑船身一排青綠舷窗、破洞、海草、整座歪斜的高尾樓 | 破洞：船殼保持封閉，外貼發光面＋肋骨＋斷板；主桅從 6.3 降到 5.35；燈籠掛點改到尾牆後方（`GHOST_HOOK`）；破洞的光跟舷窗一樣白天暗青、夜晚發亮 |
| 海嘯號 | 17 世紀戰槳帆船：又長又低、大青銅撞角、兩排槳（外伸槳架＋船身槳孔）、捲起的蠍尾＋棚頂指揮台 | 主色從紅金換成**綠金**（避開孤注號的紅白）；兩排槳都要會划（`ShipOars` 改成支援兩排）；槳葉改成前後向的平板；撞角加大後選船鏡頭框不框得住，建模時實測 |

收邊與銜接的標準（使用者 2026-11-07 要求）：該粗的邊要粗、跟相鄰的面明暗不同；懸空處要有斜撐或托架、繩索要落在木台或滑輪上、桿件穿出處要有鐵箍或孔框，沒有直接插進板面或裸切的端頭。每次修改用腳本裡的 `near(...)` 特寫鏡頭做同鏡頭的改前改後對照。
