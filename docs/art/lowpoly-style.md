# 低面數模型風格指南

《黑市商會》桌面上自製的 3D 模型（目前是四種資產建築）都依本文件的規則製作，讓新模型跟 Kenney Pirate Kit 素材與既有建築看起來是同一套美術。製作流程見 [`.claude/skills/lowpoly-model/SKILL.md`](../../.claude/skills/lowpoly-model/SKILL.md)。

## 1. 整體方向

- **低面數＋平面著色：** 由少量凸多面體組成，每個面單色受光，不做平滑法線。
- **Kenney 式材質：** 每個零件由上往下漸層（上亮下暗、帶色相偏移），不用純色，也不用圖檔貼圖。
- **高對比：** 淺色牆面（灰泥、大理石）配飽和屋頂；深色只用在窗、門、金屬等小面積。
- **不畫描邊：** 形體靠受光面與漸層區分；設計圖也不加深色外框。
- **先讀剪影：** 桌面鏡頭是高角度俯視，建築在畫面上只有幾十像素；先確定「屋頂顏色＋剪影」認得出來，細節（窗框、鐘面、頭盔）只是近看的加分。

## 2. 材質（`src/ui/scene/buildings/materials.ts`）

- 零件只能使用 `SWATCHES` 裡的材質名稱，不在零件上直接寫色碼。
- 所有色票取自 `public/models/pirate-kit/Textures/colormap.png`（Kenney，CC0）。色表每 32 px 一欄、上下兩列：左欄平色、右欄漸層。新增材質時從右欄漸層取上端與下端顏色，例如：

  ```bash
  python3 -c "from PIL import Image; im=Image.open('public/models/pirate-kit/Textures/colormap.png').convert('RGB'); c=11; y0=384; print(im.getpixel((c*32+16,y0+6)), im.getpixel((c*32+16,y0+121)))"
  ```

  （列 A 的 `y0=256`、列 B 的 `y0=384`；`c` 為第幾欄，從 0 起算。）
- 每種資產有一個專屬屋頂材質（`ROOF_MATS`），新資產或新建築類型要選一個跟既有屋頂明顯不同的顏色。
- 漸層跨整個零件的高度計算：高的零件（牆、塔）漸層明顯，薄的零件（窗台、屋簷板）幾乎是單色，這是預期效果。

## 3. 幾何（`polyhedra.ts`、`kit.ts`）

| 用途 | 用什麼 | 規則 |
|---|---|---|
| 牆、底座、箱子 | `box` | 一律加 `bevel`（牆 0.02～0.03、底座 0.04～0.05、小件 0.01～0.02），倒角會吃光，是「不像方塊堆疊」的關鍵 |
| 斜屋頂 | `kit.gabledRoof`（`gable` 山牆＋`roof` 屋頂板） | 屋頂要有厚度（0.08～0.1）與出簷（0.1～0.18），不用實心三角形當屋頂 |
| 四坡頂、船身、收窄的底座 | `loft` | 同一個輪廓上下縮放，輪廓必須是凸多邊形 |
| 柱、桶、塔、尖頂 | `prism` | 8～12 邊；尖頂用 `top: 0` |
| 柱子、樑、繩索、斜撐、木頭 | `beam` | 繩索寬 0.035、細樑 0.07～0.1、柱 0.13～0.18；圓木用 `sides: 6` |
| 窗、木桶、樓層樑、柱 | `kit.framedWindow`、`kit.barrel`、`kit.perimeterBeams`、`kit.post` | 優先用零件庫，讓所有建築的窗和柱一致 |

- **每個零件都必須是凸的。** 凹的形狀（L 型牆、拱門、環）用多個凸零件拼出來。
- **不要讓兩個零件的面落在同一平面**（例如屋頂板貼在山牆斜面上），3D 會閃爍（z-fighting）。`gabledRoof` 已經把屋頂板墊在山牆斜面上方。
- **不要讓零件穿進另一個實心零件的內部**（例如整圈實心的樓層帶包住牆），3D 看不出來，但設計圖的前後順序會出錯；改用沿著牆面的樑。
- 附在牆上的零件（窗、門、招牌）要突出牆面 0.02～0.05，才不會跟牆面重疊。
- 模型的 +z 朝向碼頭（面向中央島），y=0 是地面；每棟都要有 `flag`（持有者旗幟的旗桿頂端）。

## 4. 比例與擺放（`src/ui/scene/layout.ts`）

- 以船為基準：獨資船（`ship-medium`）在桌面上高約 4.2、長約 4.5。
- 建築在設計座標裡約 2.2 單位寬、高 2.5～5，桌面上以 `ASSET_BUILDING_SCALE`（目前 ×2）放大：佔地約等於一艘船長，最高的建築要明顯高過船桅。
- 建築放在玩家島的固定地基（`ASSET_LOTS`），必須完整落在草地安全範圍（`PLAYER_ISLAND_RADIUS × PLATEAU_SAFE_RATIO`）內且互不重疊；`tests/ui/buildings.test.ts` 會檢查。
- 島上的裝飾（棕櫚樹、木桶、旗幟）不要擋在建築正前方。

## 5. 辨識度檢查清單

完成一個模型前逐項確認：

- [ ] 在遊戲的桌面鏡頭下，只看屋頂顏色與剪影就認得出是哪一棟。
- [ ] 跟同島其他建築的剪影不同（高塔、階梯山牆、吊架、棚架……各有一個主特徵）。
- [ ] 所有方塊都有倒角，屋頂有厚度與出簷，沒有實心三角形屋頂。
- [ ] 只用 `SWATCHES` 材質，屋頂用自己的專屬色。
- [ ] 碼頭側、背面、遠景三個角度都看過，沒有閃爍、穿模或懸空零件。
- [ ] `npm run art:buildings` 產生的設計圖前後順序正確。
