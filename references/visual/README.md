## 所需參考類別

| 類別 | 用途 |
| --- | --- |
| 商船 | 獨資出航、航程狀態與收益結果的主要視覺物件。 |
| 合資船 | 呈現兩名玩家共同投資、共同承擔風險的船隻狀態。 |
| 護衛 | 角色卡、部署提示與船隻防衛效果。 |
| 海盜 | 角色卡、攻擊目標與沉船結果。 |
| 情報商人 | 角色卡，以及查看或重擲航行骰值的資訊效果。 |
| 走私商人 | 角色卡與高風險額外獲利的提示。 |
| 造船廠 | 資產卡，用來表達共同建造或出航成本相關的價值。 |
| 保險 | 資產卡，用來表達風險降低或損失補償。 |
| 打撈公司 | 資產卡，以及沉船後打撈收益的呈現。 |
| 交易所 | 資產卡，用來表達合資貨物售價或貿易收益。 |
| 事件卡 | 市場事件與航海事件的卡面、圖示與狀態提示。 |

## 後續整理方式

每份納入的參考素材應以描述性的檔名儲存，並在此文件新增來源網址、作者／權利資訊、授權條款、取得日期及預定用途。正式遊戲美術與僅供靈感參考的素材應分開管理。
